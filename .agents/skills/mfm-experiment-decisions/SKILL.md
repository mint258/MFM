# 实验判定与种子规则

权威配置：p-recipe 分支 `configs/p_recipe/protocol.json`。下文是它和 11-14 至 11-19 用户指示的要点；冲突时以这些文件为准。

## 1. 训练设置（P 研究，所有臂相同，除非臂本身就改这一项）

- 主干 C1-0（d=512，6 层，8 头，FFN 2d），FP32，TF32 关闭。
- B32 = microbatch 32，单次前向，无梯度累积，关闭逐层重算。
- AdamW，lr 3e-4，betas (0.9, 0.95)，wd 0.01；cosine 按每条运行自己的预算退火到 0，warmup 2%。
- 采样：先均匀选分子，再从允许的（最多 10 个）构象中均匀选一个。
- 梯度裁剪：前 150000 样本用 281.7，取 60000–150000 样本窗口内每步裁剪前范数的 p99，之后固定到结束。每臂各自算，阈值写入该运行目录，只报告不调参。
- 归一化：全程固定 11-07 全 TRAIN 参数。
- 预算：**筛选 3M，确认 9M。** 每 1M 存完整断点；每 500k 在固定 VAL 上记录。

## 2. 评测

- 冻结编码器，两种读出：R1 = mean(H) 岭回归 / 线性探针（513 参数）；R3 = 逐原子 MLP → [mean‖sum/N_ref] → MLP 的深读出。
- 分数 = (E_ref − E) / E_ref，E_ref 是同架构随机初始化编码器在同一协议下的误差。
- **R3 七任务均值是主分**；R1 只报告，不触发补跑。CYP 只报告。
- 不确定性：以分子为单位的配对 bootstrap，1000 次，seed 20261025，取 95% 百分位 CI。这个 CI 反映固定模型的抽样不确定性，不是训练随机性。
- 跨主干比较用原始 MAE 或 RAE；归一化分数只用于同一主干内部比较。

## 3. 胜 / 平 / 负

设 Δ = R3(候选) − R3(对照)，τ = max(0.01, 0.05 × 两者 R3 较大值)。

- **WIN**：CI 下界 > 0 且 Δ ≥ τ。
- **LOSS**：CI 上界 < 0（且未达 WIN）。
- **TIE**：其余。TIE 表示"无显著改善"，不能写成"等价"。
- **平局取更简单的配置**，但有限制：对"去掉某项"的臂，只有 R3 的 CI 跨 0 时才采纳去掉；CI 整体 < 0（去掉后显著变差、只是幅度不到 τ）时，不采纳，保留原组分。
- 侧线可以有自己的预注册门槛（head 类型线、任务解耦线：单种子 |Δ| ≥ 0.06 且 CI 不跨 0；两种子胜需两个 CI 下界都 > 0 且平均 Δ ≥ max(0.03, 对照两种子平均 R3 × 8%)）。按各线预注册执行，不互相套用。
- 对照直接复用已有运行（同 seed），不重训。

## 4. 种子（2026-11-19 起，全项目统一）

- 默认 1 个种子，最多 2 个，不跑第 3 个。
- **只有 seed0 判 WIN 的才补 seed1**，用来确认显著改善。两种子仍按原规则判定，确认胜出才采纳。
- TIE、LOSS 以 seed0 为最终结果，不补。
- 唯一例外：seed0 训练过程本身出了问题、可能拉低能力（回滚并丢失或重做样本、损失爆炸或 NaN 后回滚、续跑后损失曲线明显跳变）。这时补 seed1，日报写一行原因。用完整状态断点（模型、optimizer、sampler、RNG）续跑且损失连续的，不算例外。
- 补 seed1 时只给本臂补；对照复用已有 seed1（配方线发布 `configs/p_recipe/M2_SEED1_REFERENCE.json`，侧线不另跑）。
- **9M 全部单种子**，不论结果是否显著，两边都不补。
- 传统 ML 基线 1 个种子，随机性由交叉验证覆盖。

## 5. 轮次、合并与冻结

- 筛选按轮进行。每轮的臂以当时的 CURRENT_BEST 为基底，同轮内并行。
- 合并：同轮胜出项并入基底得到新的 M。互斥的两项都胜出时，保留 Δ 较大者。若新一轮基底已经变了（M3 ≠ M2），需加一条 3M 合并运行对新基底配对比较，胜了才更新 CURRENT_BEST。
- 侧线两种子确认胜出的项，直接并入最终配方，由配方线合并，不再经用户确认、不另开验证轮。侧线在最终报告里写清每个胜出项的配置键和对照基底。
- 某臂没能在时间盒内完成判定：按未胜出处理，不等待。
- 用户宣布"最后一轮"后，不再开新轮。所有轮和侧线都有最终判定后，发布最终 CURRENT_BEST，记一行日志，即配方冻结。
- **冻结前不提交任何 9M。** 9M 是确认阶段，按卡型优先级并行提交，启动时读取并记录提速开关状态，中途不切换。
- 9M 里只描绘缩放曲线的运行（如 25 万、50 万分子）不做胜负判定。

## 6. 预注册的写法

- 每个比较写清：对照是谁、主指标、配对方式、判定规则、平局处理、种子规则。
- 写一张"观察 → 结论"解读表；其他组合如实报告，不追加臂。
- 负结果如实报告，不当作工程故障。

## 7. 已知的噪声量级（用于解读，不改判定）

- M2 两个种子的 R3 差：0.00205。
- B3 两个种子的 R3 差：0.0339。
- 同科学配置的 M1 与首轮 A1 相差 0.042。
- 不同基底的噪声不能混用。

## 评测方式（2026-11-23 起）

- 每个预训练条件（S、P、D 及任意家族组合）都同时报告冻结读出（R1、R3）和全量微调（编码器全部可训练，四任务 qm9.U0_atom、qm9.homo、exp.LogD、exp.LogS，三个微调种子，含随机初始化 scratch 对照；协议见 p-recipe 的 docs/p_recipe/USER_DIRECTIVE_20261122B.md 第 3.1 节）。
- 理由：P 研究中冻结读出低估了预训练的价值（例：U0 在冻结读出下随训练变差，全量微调下持续改善）。
- 进行中的线按各自预注册的规则判定；新开的线和主实验 E2 在预注册时写明两者如何共同判定。
