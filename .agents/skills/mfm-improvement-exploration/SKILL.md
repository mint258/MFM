# 改进探索：诊断、设计新臂、收尾

本 skill 规定**怎么找方向**。判定规则（τ、CI、种子）见 `mfm-experiment-decisions`；任务书怎么写见 `mfm-taskbook-standard`。执行窗口只执行任务书列出的臂；本 skill 的产物是**提议**，新臂要由用户写进任务书或 USER_DIRECTIVE 才能跑。

## 0. 基本立场

- P 研究的核心假设：**P 结果弱，先当作配方、损失、架构或读出的问题，而不是标签不好。** 先把单独的 P 推到应有的水平，再把方法迁到 S、D。只有在这条线按计划做完、仍然没有改善时，才把"该标签信号弱"作为负结果如实报告。
- 诊断只用来决定**既定或新提议臂的取舍和顺序**，诊断本身不产生采纳结论。采纳只看筛选判定。
- 诊断支持的臂照样可能输：P0 诊断引出的 A1（D1）、B4（D4）胜出，而 A2（D3）、A5（D2）、B1（D5）都判 LOSS。所以每个臂都要经过筛选，不因"诊断很有说服力"跳过或放宽判定。

## 1. 诊断顺序（按顺序做，前一步没过不进下一步）

1. **结果本身是否有效。** 只查会悄悄破坏结论的地方：训练过程（损失爆炸、NaN、回滚丢样本、续跑后曲线跳变、裁剪阈值异常）、checkpoint 与条件的对应、归一化是否为固定的 11-07 参数、标签与 ID/几何对齐、TRAIN 与下游泄漏。训练过程出问题 → 按种子规则的例外补 seed1；基础设施故障 → 修好、从完整 checkpoint 续跑，不当科学结果。
2. **差异是否超过噪声。** 和**同一基底**的种子噪声、τ 比较（M2 两种子 R3 差 0.00205；B3 两种子差 0.0339；不同基底的噪声不混用）。TIE 就是"无显著改善"，不靠补种子、换读出、挑任务把它变成胜负。
3. **基底是否是当前的。** 和 CURRENT_BEST 比了吗？旧基底上的胜出不能外推：任务解耦线的构象分解 D 在旧 M1+C 基底上 WIN（R3 +0.113），换到 M2 上的 D′ 两个种子都 LOSS。
4. **零训练诊断**（第 2 节）：在已有 checkpoint 和标签上做前向和统计，找出最可能的原因。
5. **设计新臂**（第 3 节）。

## 2. 零训练诊断

### 2.1 做法

- 只用已有 checkpoint 和已有标签做前向、读出和统计，不训练。
- 固定样本：`tools/p_recipe/diagnose.py` 的 5000 个 VAL 分子（seed 20261112）；需要构象时取允许的全部构象（≤10）。
- 统计用 F64；不确定性用以分子为单位的 1000 次 bootstrap（seed 20261025），条件之间配对；重抽固定的折外预测，不在每次重抽里重新拟合。
- 资源量级：约 1 GPU-h 以内，或放 CPU 节点；预计 >2 小时且任务书没列的计算，列"待用户决定"，不执行。
- 复用已有工具，不重写：`tools/p_recipe/diagnose.py`（P0 的 D1–D6）、`tools/p_recipe/evaluate.py`（支持 `configuration['layer']` 的逐层 R1/R3）、`tools/p_followup/collapse_composition.py`（CEV/CVF）、head 类型线 `tools/p_heads/h_*.py`。
- 看结果前预注册假设、预期方向和"支持 / 不支持 / 不确定"的门槛（例：支持 = CI 下界 > 0 且 Δ ≥ max(0.10, 参照 × 20%)）。门槛没过就写"不支持"，不因 CI 排除 0 就称支持。
- 重要观测写成发现记录（`mfm-paper-records` 第 2 节），标明是原始观测还是已验证结论。

### 2.2 四类诊断（从标签到读出依次排查）

| 类 | 问什么 | 项目里已有的诊断 |
| --- | --- | --- |
| 标签 | 标签里有多少可学的信息？哪部分是噪声、冗余或尺度问题？ | D1 元素可解释性（各家族 VAL R² 0.659–0.999）；D3 冗余（参与率；跨状态原子电荷参与率约 1.0）；逐位相同或相加关系的字段（COSMO 面积三状态逐位相同；r41 + r54 = r83，两项各约 368 eV 的构象差拟合出 0.057 eV）；同分子构象幅度 vs 跨组成幅度（约 1/4–1/18）；存储精度（F32 让 r83 的 414/23432 对构象差变为 0）；留出拟合度（r624、r625 R² 0.99）；各家族在总损失中的权重占比（梯度字段约 2/109） |
| 优化 | 梯度被谁主导？ | D2 梯度集中（3 个字段/头占 54% 梯度能量，前 1% 分子占 52%） |
| 表示 | 编码器学到的表示是否塌缩、编码了什么？ | D4 表示谱参与率与近常数维（P 原子/分子 2.356/1.037，S 3.409/2.077）；末层塌缩（mean(H) 98.2% 方差在一个方向）；CEV / CVF / CVF_res（组成解释方差、分子内构象方差占比） |
| 读出 / 头 | 信息在表示里但没被读出来？头的结构是否合适？ | D5 逐层读出（P 第 3 层 R3 比第 6 层高 0.040）；下游 H 的来源比较（不同层、白化、PMA 输出 z、拼接）；PMA query 注意力熵；原子目标的元素解释率 |

## 3. 从诊断到新臂

### 3.1 规则

- **一个臂相对 CURRENT_BEST 只改一处**，写明它回答哪条诊断、预期方向是什么。
- **只用一个值，不扫参**（例：X2 把梯度字段损失权重乘 5，只试这一个值）。
- 想知道一个组分贡献多少，就"去掉"和"加强"成对设计（X1 去掉扰动梯度、X2 加大其权重）。"去掉某项"的臂只有 R3 CI 跨 0 才采纳去掉；CI 整体为负时保留原组分。
- **检验机制要用只破坏该机制的消融**（例：T3 把 PMA 的注意力权重换成每原子 1/N、其余结构和参数量不变，检验 B3 的增益是否来自"选择性加权"）。
- 机制解释被诊断否定时，放弃这个叙述，不再据它设计臂。例：PMA query 注意力接近均匀，"按内容选原子"不成立；塌缩组成检验 A-H1、A-H4 都不支持，"末层主方向编码组成、压缩构象信息"不能写成已证实。
- 需要先建依据表的臂，先建表再跑，对不上的不猜（例：F1/F2 多保真度先按注册表物理定义建 PM7–xTB 配对表，单位、符号、粒度对不上的列为"未配对"）。
- 以下不能作为臂，碰到就是停止条件：改标签定义、mask、归一化参数、字段集合、判定规则。看到结果后也不回改任务名单、划分或判定口径。
- 预注册"观察 → 结论"解读表，其他组合如实报告，不追加臂。

### 3.2 已有的"诊断 → 臂"对应（作范例，状态截至 2026-11-19）

| 诊断发现 | 臂 | 结果 |
| --- | --- | --- |
| D1：元素能解释大部分标签变化 | A1 元素参考 | WIN，进 M2 |
| D3：跨状态字段高度相关 | A2 状态差值目标 | LOSS（最差的臂） |
| D2：梯度集中在少数字段和分子 | A5 | LOSS |
| D4：P 表示谱远窄于 S | B4（γ 取 S 原子 H 标准差中位数） | WIN，进 M2 |
| D5：中间层读出更好 | B1 共享投影器 | LOSS |
| 均匀池化读出 P 分子标量 | B3 PMA 注意力池化 | WIN（R3 0.359 → 0.475），进 M2 |
| 冗余与相加关系的字段放大 size 家族权重 | 任务解耦线 C 去冗余 | LOSS |
| 构象幅度远小于组成幅度 | 任务解耦线 D / D′ 构象分解 | 旧基底 WIN，M2 上两种子 LOSS |

## 4. 做多深就收尾

- **筛选**：3M、1 个种子；只有 seed0 WIN 才补 seed1；9M 只做确认，不做探索。
- **一轮**：本轮臂都以当时的 CURRENT_BEST 为基底并行跑；全部有判定后按规则合并，没有胜出项就记 M(n+1) = M(n)（第 3 轮 C1–C4 全 TIE，M3 = M2）。
- **开下一轮要用户的指示**。一轮没有胜出项时，日报"待用户决定"里提议：收尾，或下一轮要测的方向（附依据的诊断）。执行窗口不自行开轮。用户宣布"最后一轮"后不再开新轮。
- **侧线**：一份任务书 = 固定的臂清单 + 运行数上限（例：3 条必做 + 按规则触发的 seed1，最多 4 条）。全部臂有最终判定即收尾：最终报告 → 完整回归 → 开 PR 不合并 → 不再占 GPU。没有胜出项照样收尾，写"无胜出项交接"。
- **单个方向**：seed0 判 TIE 或 LOSS 即结束，不在同一线里追加变体、换参数值或补种子去救它。
- **时间盒**（2026-11-25 修订，见 `docs/interfaces/TIMEBOX_RULE_20261125.md`）：工程失败修好重跑、不计次数；同一根因的科学或方法失败修复 2 次后仍失败，或诊断修复累计超过 4 小时（不含排队和计算）→ UNRESOLVED，取保守默认（该臂记缺失 / 按未胜出处理 / 退回原头），主线继续。
- **新想法**：日报末尾记一行，不执行。
- **阶段收尾**：所有轮和侧线有最终判定 → 发布最终 CURRENT_BEST（冻结）→ 9M 确认 → 最终报告，阶段结项。
- **迁到下一阶段**（S、D）：把 P 研究里胜出的方法和这里的诊断套路直接用上，不从头探索。S 做 S 专属旋钮的消融；D 先回答"哪些性质该进 D 的目标"（D20、完整 RDKit、CheMeleon 式 Mordred 三套比较），再直接试最终 P 配方。用户预计 S、D 提升空间有限，按浅的深度规划。

## 5. 记录

- 每个臂的文档写明它由哪个诊断或假设引出、预期方向、实际结果（`mfm-paper-records`）。
- 负结果和"不支持"如实写，不当作工程故障，不改写成"等价"。
- 诊断里观察到但没有验证的机制，标为假说。
