# Expansion runtime evidence

The quota publisher records actual Main account quota every 30 seconds; it has no overall wall timer. It validates the raw user/device/used/positive finite limit, source identity and freshness. Own allocation credit is restricted to owned immutable output charged before the quota query started. Large UFF producers use an incremental inode ledger instead of full directory walks.

The startup launcher binds an immutable reviewed template and source inventory to the actual Slurm CPU node, CPU count, UID, boot and job ID. It creates the actual producer plan and proof only inside the real allocation, never invents a future source hash or completed job. It does not claim scientific completion from process exit. No fixed Slurm memory request, GPU or artificial overall timeout is added.

The direct compute-0-20 source smoke executed 26 tests successfully on 2026-11-03 (Python3.11.14, RDKit2025.09.5, PyArrow17.0.0, DuckDB1.2.2). This covers source/identity, binary64 materialization, no-fill/no-retry and cache-prefix boundaries; it is not the 10K scientific pilot or full dataset acceptance.
