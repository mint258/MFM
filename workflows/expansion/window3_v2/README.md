# PubChem 窗口三 v2

执行 2026-11-05 根任务书。E1 复用已完成的 R/N 各 500 万队列及首批各 125 万的来源结构；不重新计算最近邻、相似度或去污染。

`producer.py --config …` 直接流读来源。`pilot` 固定抽 R/N 各 5000；`full` 处理其余 249 万。全批可按 `(stream_rank-1) % shard_count` 互斥分片，最终与试跑合并，试跑分子不再计算。每个分子只执行一次 D20，一次原 ETKDG 嵌入、每个内部候选一次原 UFF；沿用已建立的 S′ 固定 30 内部候选配方、能量顺序和 0.5 Å 去重，最多交付三个实际构象，不补足、不重试。D3/逐原子 SASA 沿用原数值函数和参数。有效内部候选保留供未来扩展，交付构象可直接用于未来单点。

`kernel.py` 直接加载已部署的原函数，沿用固定种子的 SHA 算法；这只是科学配方规定的随机种子，不是记录或文件校验和。生产路径不计算内容哈希。原 v1 家族中的历史 digest 列可空，新增校验和均为空。来源版本字符串沿用已冻结版本。

在生成端一次检查分子/构象 ID、坐标、D20 长度和逐原子 SASA 对齐。按原登记表物理范围产生掩码，新增比例只报告。按 v1 的 D20/D3 家族模式写 Parquet，另存 geometry、source_status、validity_masks、candidate_cache、timings。清单只有 `path,size,rows`。不另起 QA、不二次读回、不写验收收据、不设内存/时间/成本停止门。

分块 gzip spool 和 `done.json` 是恢复检查点。中断恢复读取未完成块的 spool；已开始而未返回的分子记 UNKNOWN，禁止重新调用科学核。原文件保留，新的写出尝试使用新目录。已完成块直接采用。作业绑定真实 Slurm 分配并持有输出锁，防止重复生产。

`statistics.py` 只聚合既有特征和既有近邻分数。覆盖变化的查询群体明确为固定的新增 250 万结构，报告加入前对 v1 的近邻分布及加入后的直接覆盖（包含自身）。其余池和原固定随机 100 万查询的扩充后近邻分布没有新计算，不由这个直接覆盖结果推断。

新逻辑单测在 `test_producer.py`；完整回归仅在新开 PR 前执行一次。草稿 PR1 保持未合并。大数据和运行检查点均在仓库外。
