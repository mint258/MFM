## CPU-only order and boundaries

Three synthetic tests run first: normal ZIP plus deliberately nonexecuted
pickle bytes; CRC corruption/unsafe names/directory bounds; bounded ZIP64 and
truncation. Actual CPU results are pending, not claimed PASS by this source.
After them the consumer checks the Main regular file UID/actual declared size,
computes the first complete wholeSHA while preserving fstat, and writes the
first observed data reference. That hash is a new actual CPU observation, not
an expected transport checksum or author signature.

The reader bounds classic EOCD or ZIP64 before constructing ZipFile:
4096 entries,16MiB central directory, single disk, no trailing bytes and
in-file offsets. This follows the [PKWARE format](https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT)
and uses stdlib public ZipFile for members. It rejects duplicate/unsafe/long
names, symlinks, encryption and methods other than stored/deflate as UNKNOWN;
it does not try passwords or alternate tools. All members are streamed with
bounded1MiB reads to CRC/EOF/SHA, including empty directories. No extractall,
pickle import/load/opcode execution, native SDF parsing, CSV data decoding,
RDKit or normalized identity is called. Names are filename-only hints.

inventory.jsonl is durable and bounded, with per-member bytes/CRC/SHA.
All declared/actual expanded bytes must conserve under Root's explicit cap.
The original archive stays in place and unchanged. Expected author basenames
Kraken.pickle or Drugs.sdf/Drugs.csv are reported uniquely or UNKNOWN/HOLD;
they are not assumed true from README. RSS/MemAvailable/current free disk and
elapsed allocation wall reserve stop naturally without signals. Long hashes
retain the same live PID/startticks/boot/job/node binding; no stale proof is
turned into a new fresh proof.

Failures preserve partial inventory, actual firstSHA if already complete, and
stderr/receipt with pending actual terminal cost. No retry/download is hidden.
Even successful full CRC does not accept source IDs, native pickle safety,
molecule/conformer counts, charge/stereo completeness, full identity,
decontamination, pool, UFF/QM or training. Those need separate Root-reviewed
safe native-format stages. Existing failed GET parents and previous partials
remain historical; no old failed job is called C0. Cost is report-and-continue
with scientific quality unchanged.
