# One official2013 QM7b ZIP, opaque acquisition only

The only URL is `https://www.mrupp.info/Data/2013dsgdb7njp.zip`, the actual dataset
href on original author Matthias Rupp's2013 publication entry. Exact byte-copied
primary memo and real HEAD JSON are required small SOURCE, with actual prior pins.
The prior HEAD observed HTTP200/application/zip/2671083 bytes; it is not an archive
SHA or graph/mapping observation. Source metadata and original unknowns are kept.
No initial archive SHA or fabricated data locator is admitted: plan DATA is empty.

Root independently approves this exact source, scope and network action. Entry:
`python -B -m secondary_qm7b_official2013_acquisition_v1.run --plan PLAN --startup-proof PROOF`.
Fresh Alpha UID1264 CPU16/no_mem/noexclusive, analysis/pilotfalse/performancefalse,
600s,2GiB, scope7 registered caps and200GB effective free remain required.
One sequential network reader is reported honestly, not16 busy download workers.
Python3.11.14 and the existing controller/proof/storage interfaces are retained.

Three new synthetic methods run before network, original DATA or Budget. They
cover exact URL/no redirect and HTTP/HEAD mismatch, bounded retained response/EOF/
no overread, and every member bytes/CRC plus declared expansion/member ceilings.
No old test methods or scientific parsers run. Source directly imports the frozen
original `NoRedirect`/`safe_headers` objects and original CSV6 Budget/journal; it
does not call the frozen11-source acquire engine or edit its catalogue.

Exactly one ordinary GET attempt; default proxy/network environment is inherited.
No redirects, mirror fallback, ranges, auth/CAPTCHA bypass or automatic retries.
403/429 and any non200 response are retained as a bounded opaque prefix and HOLD.
At most16MiB body bytes are read. Declared/actual byte length must both equal the
actual original HEAD2671083 for archive closure. A mismatch retains the actual
headers/opaque response and never silently switches source. The complete actual
response file is flushed/fsynced; first producerSHA is computed in this allocation
and verified again on a stable owned regular FD before any ZIP decoding.

ZIP limits are at most20000 physical entries and256MiB total uncompressed bytes.
Declared mass is checked before member decode; actual mass/whole EOF/CRC32/SHA256
are verified for every member. Encrypted entries HOLD without password attempts.
Duplicate names, directory flags, original filename, compression method, sizes,
CRC and ordinal remain in DATA; no name/ordinal/dedup is treated as identity.
No archive path is extracted, imported, followed or executed. All uncompressed
member bytes, including all original documents, are preserved unchanged in one
stable concatenated opaque `.raw` blob. Each member's offset/bytes/SHA segment is
recorded only after raw bytes are fsynced. Original compressed ZIP remains too.
This avoids thousands of extracted files and transient budget-tree races.

Coordinates, SMILES, graph/key and row mappings are not parsed or inferred.
Even names `moleculeNNNN` or a future7211 count do not prove MAT row identity.
This job is only transport/ZIP inventory; a later separately reviewed CPU format
inspection must determine what documents/identity fields actually exist. Receipt
and summary contain counts/refs, not original member text. CRC C0 never releases
the graph/SMILES/MAT association, current original UNKNOWNs or decontamination/pool.

Original CSV6 Budget reserves its unchanged1GiB+128MiB drain inside2GiB, and tracks
RSS/MemAvailable, current capacity minus all registered caps/200GB, and wall reserve.
It stops naturally, preserves partial response/member blobs/inventory, and never
signals other work. A600s ceiling is not a measured cost forecast. Root records all
actual startup/network/failure/terminal cost; cost overruns report-and-continue,
while integrity/quality gates remain unchanged. No stage was run by SB4.

Metadata is supplied by the separate single-protocol thin package
`secondary_cpu_readonly_qm7b2013_v1.materialize`. Its controller is byte-identical
to frozen v13; no new scheduling algorithm or old module mutation is introduced.
