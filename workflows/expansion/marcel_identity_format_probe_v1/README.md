## Drugs

Author loader [drugs.py at the frozen code locator](https://raw.githubusercontent.com/SXKDZ/MARCEL/dae6b3b824b68d1362ed3b9fa23b34a45fa5366c/benchmarks/data/drugs.py) reads `ID`, `_Name`, and `smiles` from the SDF and matches `_Name` to literal CSV `name`. This is a code version, not a claim about the Drive payload's release version. This probe retains every physical SDF record and CSV record, including empty/invalid/duplicate/missing/zero/orphan identities. There is no author-count cutoff, max-conformer truncation, split selection or chemical filter.

The SDF title is recorded as `_Name_title`; only native `ID`, `smiles`, and an explicit `_Name` property are decoded as identity UTF8. Original exact bytes are preserved through UTF8 text or base64 on invalid UTF8. Only CR/LF record terminators are removed, never whitespace/leading zeros. Duplicate properties, missing M END, unterminated records, or explicit `_Name` properties conflicting with the title are UNKNOWN. The title is paired for source-format inventory only; an explicit `_Name` property marks its interpretation ambiguous. MolBlock geometry and assay property values are traversed/hashes only, not decoded or rewritten. This is not proof that RDKit will parse every graph or preserve every stereo assignment.

`NameCSV` uses actual original `CSVProjection.feed`, `.finish` and `.append` method objects with independent real MARCEL source/header/selected-field callback seams. Its custom `finish_field` preserves the literal selected bytes instead of discarding them into the original aggregate counters. The original six-source constructor and selector are not called, not modified and no fake source ID is introduced. Only the exact header `name` is selected; duplicate/missing headers and row-width mismatches are UNKNOWN. Assay bytes are not text/numeric decoded.

`source_identity_rows.jsonl` is flushed/fsynced before each at-most256-row derivative SQL transaction. The new, job-owned SQLite file is only a pairing index; no pre-existing project SQLite is opened. All original records stay in the journal/index with their physical ordinals. Aggregates report literal-byte duplicates/orphans/conflicting smiles; an orphan or duplicate is not a chemical exclusion. The complete member SHA and final row conservation are required. Interrupted source prefixes remain partial and cannot be accepted as complete.
