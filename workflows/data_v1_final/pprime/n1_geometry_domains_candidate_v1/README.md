## Read-only supplement reader and its admission limit

`reader.read_packet(reference, expected_task, *, origin_owner, current_uid,
current_endpoint, actual_terminal_closure_reference, relocation_reference=None)`
is called only inside a future independently fresh-admitted CPU entry, after
three synthetic methods and before no scientific worker initialization. It:

1. Reuses original N1 `contract.validate_task` for its exact old task schema;
   old idx0 validation is not relaxed. Requires literal origin
   `(endpoint,uid,job_id)` and an actual terminal-closure ref. Distinct current
   endpoint or UID requires a real relocation authority ref.
2. Opens the closed regular non-symlink packet read-only, validates current UID
   and exact size, hashes the complete compressed file, seeks the same FD and
   reads through gzip EOF/CRC with the original 256-MiB decode bound. Full fstat
   and path frame including ctime must stay identical.
3. Requires the real `N1_PPRIME2_PILOT_GENERATION_PACKET_V2`, original task key,
   source authority, unchanged count flags and no source-only Common release.
   Retains actual job/UID/PID/start-ticks/boot, references, errors, native orders
   and all optimizer events. It never writes/claims an attempt.
4. Reuses original `pprime.geometry.geometry_hash` for baseline, every finite
   event and the actual `packet['supplement']`, with LE int64 Z + LE float64 xyz.
   Preserves the full baseline row SHA, atom order, anchor, original seed and
   selected extra event. A real second must match one retained native optimizer
   event with finished/converged/finite/stereo flags, coordinates, energy and SHA.
   Missing baseline/extra stays unresolved; it is not a synthetic success.

No worker_init, embedding, force field, RMSD recomputation, native QM invocation,
ledger mutation, file deletion or packet rewrite occurs in the reader. It is
not an admission implementation: the future port must actually load/validate
terminal close, claim/start/producer pins, full role/source authority and actual
accounting before calling it. A structurally valid ref alone is not a terminal
C0 proof. Failed/TIMEOUT/UNKNOWN source attempts remain in the census/cost.
