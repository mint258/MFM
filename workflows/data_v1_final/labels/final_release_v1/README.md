There was no complete old publisher: build_registry.generate returns draft1; normalization_v1.run even after full replay still says D4_published=false; streaming.reduce provides the original weighted Spearman but does not freeze the registry. `contract.validate_directive(directive,allow_nonexecutable=True)` reads only small Source/metadata and returns status/missing/source_references/data_references/directive plus internal parsed metadata. Missing actual D4/Root/Model refs yield NONEXECUTABLE and no running plan; current-family C0 is deliberately not a candidate prerequisite. Metadata validate writes the bounded subset of that response. This avoids the D2/D4 publication/D3 export loop. Current candidate DATA can be exported/QA'd in the same parent. After real parent C0 and independent Root review, metadata.publish creates the only final consumer release.
