original F64 validator; the allocated parent alone writes its new output. No
native child or optimizer is created. A read error fails the import and leaves
all original files and claims unchanged; it does not become a scientific retry.

packet status and supplement presence separately. Unknown/unstarted/consumed
states and receipt resource-observation failures are preserved. Successful
