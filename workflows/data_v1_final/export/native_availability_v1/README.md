## Probe boundary and reuse

Original WP5 archives use the dictionary-Zstd `records` schema from frozen
wp5_archive_v5.py, not Pprime's gzip `raw` table. Fixed SQL reads scalar columns
and length(raw_frame)/length(metadata_frame), never SELECT* or raw_frame,
parsed_molecules or wire_frame BLOBs. Exact execution ID is mandatory; no
historical/latest fallback. Each of16 worker threads handles unique keys and
at most one active read-only SQLite connection; the same closed archive may
have up to16 independent read snapshots, all recorded/closed. This is metadata
parallelism, not duplicate QM or raw-body decoding.

A1 permits only metadata_frame<=4MiB and metadata_bytes<=2MiB, checked before
fetch/decompress.12 declared dictionary files are each<=2MiB,total<=16MiB,
whole-SHA checked. Each thread owns its own original wp5_archive_v4.Zstd context
and calls the frozen decompress method with the exact metadata byte count.
Metadata JSON rejects duplicate keys and checks audit/owner/execution/package,
dictionary identity and input hashes. The original catalog's explicit
str(context.task_id) conversion is recorded, preserving its native type/value;
other owner integer fields are matched by exact type and value.

Output member names/bytes/SHA are declarations only, never native token/frame
checks. Inputs remain HASH_ONLY_NOT_SAVED. No ArchiveReader.get, iter_staged,
pickle, original renderer/compute/invoke, raw program, source labels/coordinates
or original Parquet values are opened by probe. Raw-key absence is explicitly
reported, not converted to a source label failure; incomplete/error scope is
nonzero with all partial evidence retained. Every native-field matrix entry is
PENDING_NATIVE_TOKEN/FRAME even when a raw row/member declaration exists.

Reuse: the existing central queue/startup and source-status resource observer,
original dictionary-Zstd implementation, and existing audit/owner/catalog pins.
No general data layer, queue, new scalar/tensor mathematics, or duplicate old
codec/native72 tests. Only3 new pure methods validate: fixed metadata projection
