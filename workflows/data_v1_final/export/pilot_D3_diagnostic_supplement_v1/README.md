Source only. This author ran no Python/AST/tests/data/Slurm and read no active
scientific DB. Original frozen D3, running D4, D5 and scientific masks remain

## Proven Source seam

Fast55k `fast_coverage.selected_index` selects every original native rid for all
frozen55k MIDs, before D5 eligibility is built. `part` retains its base and all
14 original typed task rows; `complete_mass` proves every field's original
denominator and146 fields. Typed `compact_mask_json` remains the original
source/new/review mask. The later eligibility sidecar adds `fit_eligible` to
owners without rewriting entries/masks.

The actual omission is in Fast D3 `domain.build` (`selected=0` for held TRAIN
geometries), `source.one` (skip selected0), and `writer.write` (selected1 only).
Consequently existing D3 pieces/stores do not contain held labels. Flipping
writer membership or copying old stores alone would produce an incomplete
diagnostic payload.

This exporter reads only closed inputs after ordinary D3 actually C0. It makes
a finite private domain from the original D3 table schemas, held rows and real
native graph anchors. Original source domain is readonly; its first whole DATA
SHA/current-frame check happens in this admitted CPU parent, not login. No
future domain hash is invented during plan construction.

The diagnostic reader uses the closed Fast55k typed catalog's exact persisted
canonical owner, atom sequence and original row-signature/mask parity. It does
not apply D5 `fit_eligible` as a scientific invalidity mask. It projects only
real held native rids through all original14 tasks. A private full-code binding
of original Fast D3 `source.one` substitutes this reader IO only; extraction,
raw-cell/frame checks, tensors, native r73 ordered records and mask functions
are unchanged. Original raw closed cell Parquets remain necessary for the
original lossless component/r73 extraction; the numeric typed cache alone
does not encode all ordered endpoint/channel source dictionaries. Original
RawRows retains inherited producer SHA, stable current FD/footer/row count and
actual input file+bundle hashes, not a new whole575GB hash claim.

## Actual seen intersection and complete target lineage

Seen means an actual MID in ordinary D3 `exported`, joined to original
`molecules.role=TRAIN`; the CPU proves these are exactly the50k retained TRAIN
MIDs. The diagnostic MID set is that set intersected with the formal D5 global
20k. No20k coverage or intersection size is claimed by Source.

The actual CPU reads the original D5 `diagnostic_base_reference` and
`diagnostic_targets_reference`, including all real base, direct child and
actual unperturbed input-view targets. For the seen intersection, this entire
GID set must equal the closed D4/D3 excluded domain. Every target must exist in
the old domain, have selected0, and never occur in ordinary `exported`. Base
IDs must be original last fixed-random ranks; child/input-view parents must be
their exact original D5 base. No task-name/coordinate alias or new geometry is
created. UFF held bases are geometry-only; no Pprime labels are imputed.

- `actual_seen_diagnostic_molecule_ids_reference`: molecule_id,sample_role.
- `selected_diagnostic_geometry_ids_reference`: molecule_id,geometry_id,
  geometry_source,parent_geometry_id,view_id,is_base,
  original_fixed_random_rank,original_N,native_record_id,sprime_conf_idx,
  diagnostic_base_geometry_id,sample_role,training_excluded.

The second index covers all selected base/child/input-view GIDs. Original N and
base rank remain unchanged; derived ranks are NULL. Consumers sample UNSEEN
from is_base only and attach actual derived label/input-view geometry without
inflating N. The receipt reports global20k, actual seen50k, actual intersection
and outside-seen counts. An empty intersection cannot create a third role.

TRAIN/VAL/FULL/embargo. It is retained unchanged. Records therefore preserve
the actual seen molecule's `effective_role=TRAIN` and original opaque
source_role, plus explicit `sample_role=diagnostic_role=TRAIN_UNSEEN_CONFORMATION`,
`diagnostic_only=true`, `training_excluded=true`, `train_eligible=false`.
These sample flags never alter scientific value/mask arrays. The closed
supplement manifest supplies the actual diagnostic membership authority.
SB1's adapter maps this separate sample role to TRAIN_UNSEEN; it must never
merge these records into ordinary TRAIN just because molecule role is TRAIN.

Original Fast D3 writer/codec is reused through a private metadata-only
function binding. Permanent source float64 sidecars precede the same original
single float32 codec cast. All146 fields and original missingness/shape/frame
rules remain; r674 is lossOFF with its original six values/masks retained;
r73 preserves ordered endpoints, both basis channels, direction, duplicates,
onsite presence and entry ordinals. Exact actual D3 configurations and the same
D4 statistics are reused without a new fit or scientific policy.

Original store names are retained. To avoid collision with ordinary names,
the wrapper declares `store_namespace=pilot_D3_diagnostic_supplement_v1` and
`consumer_alias_prefix=diagnostic/`. Local consumers use a separate diagnostic
directory/catalog prefix, preserving origin name/path/SHA. Closed-store refs
have the same actual Fast55k `{name,path,kind,geometry_source,manifest_reference,
data,f64_authority,records,molecules,schema_sha256}` body as the original writer.
