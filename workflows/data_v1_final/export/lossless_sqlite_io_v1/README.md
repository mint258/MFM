# Internal SQLite lossless storage

Only new derived temporary/domain SQLite BLOBs use DV1Z1 plus zlib level1. After decompression bytes equal the original D5 lossless JSON tree/F64 pool/signature exactly. Decode uses the original decoder, supports prior uncompressed BLOBs, enforces the same uncompressed molecule cap and rejects incomplete/trailing compressed streams. Scientific values, masks, ordering, IDs and dtype are unchanged. Raw LMDB/WP5/Sprime sources, final family MFM3 LMDB and permanent F64 sidecars/parquets remain original. No pickle storage.

encode_raw produces precisely the old original bytes while constructing the same original tree once. The shared small byte proof is included in existing Source methods before DATA; it is not an additional scientific test suite. This new internal storage namespace does not patch old modules or running jobs. New operational plans and actual Parent references must explicitly bind this source.
