Stage60 external full downstream runner, static draft
==================================================

This directory is new external execution code. It changes no pretraining source,
model, optimizer, task, split, three-epoch exposure or frozen protocol. No author
has run Python, Torch, tests, benchmark target readers or SSH. Root must perform
AST/import/CLI-help checks and the small CPU tests before scientific execution.

The real frozen authority is the physically bound protocol, not this README or
a synthetic report. `formal_plan.compile_plan` derives all 27 encoder entries:
24 joint active-set/seed entries, three auxiliary SDP strategy entries, including
the three paired NONEs. Each encoder has 41 main fits and 21 complementary graph
linear fits: maximum1674, all35 output tasks, primary32 endpoints/239 cells,
all-task269 cells. This is not the old QM7/CYP training-only development panel.

Files and actual APIs
---------------------

* `formal_plan.py`: stdlib frozen-scope accounting and exact source-typed scalar
  history comparison. `compile_plan(protocol, protocol_file_sha256=...)` and
  `select_fit(plan, fit_id)` never read targets or run a model.
* `formal_readout.py`: actual `SharedBackboneMFM.encode_atoms` input is only
  native `x,pos,batch,ptr`. `load_encoder` weights-only loads an actual typed-sealed
  complete three-epoch FINAL; NONE must byte-match its actual paired seed init.
  It checks actual consumed exposure rather than inventing equal optimizer
  update counts across missing-label conditions.
* `prepare_h0_cache(...)` serializes actual native384 FP32 H0, input/coordinate/
  native-ID/provenance hashes and actual endpoint state. No target values are in
  this cache. Dataset caches belong to ONE encoder and are shared across all62
  fits. Root may remove/rebuild a cache only after all consumers have closed and
  no active fit holds it. The whole-phase104GiB accounting includes caches and
  atomic pending files; a cache is not a free allowance outside the quota.
* `train_fixed_readout(...)` uses the genuine source-aligned Linear64/ReLU/main
  or raw-H0-mean/Linear complement, existing Xavier/zero-bias initialization,
  common readout seed0, single-tensor AdamW, B32, exactly20 epochs and a natural
  final smaller batch. All-unknown and unready sources stay in the inventory;
  their exclusion from optimizer inputs is common across all encoder variants.
  Per-task masked losses use the COMPLETE fixed task denominator. The source
  order is the actual frozen role-view order; no target-driven reordering occurs.
* `evaluate_outer(...)` checks the actual `test` role against physical source
  membership. It does not relabel test as `train_inner_validation`, invoke the
  role-limited production evaluator with a fake role, or accept supplied metric
  numbers. Graph metrics are FP64 inverse-affine observed-label error sums/counts.
  SoM ranks all original candidates by raw logit descending/native ID ascending,
  requires complete candidate supervision, reports the five status partitions,
  and retains null unavailable scores. Train-normalizer unavailability remains
  null and is reported separately from missing test labels.
* `TypedOfflineJournal`: actual W&B0.28.1 explicit commit plus fsynced complete
  typed payloads. Closed real `.wandb` history is decoded by the actual project
  `tools/export_wandb_history.py`. Exact scientific keys/steps/ACK/seals/numeric
  values are required; integral floats restore their SOURCE type before exact
  comparison. This does not reuse the old 20,000-row reader cap or float tolerance.
* `run_formal_readout.py --request PATH --request-sha256 SHA`: actual cache or one
  actual fit worker. `--help` is stdlib. It imports the exact physically bound
  project/provider, verifies input bytes before/after, uses the actual existing
  formal CLI's runtime observation function without its pretraining `main()`,
  and requires an owned Slurm job/full UUID. A root resource parent must retain
  the real cooperative UUID lock, foreign-process rejection, RSS/GPU/whole-phase
  output/wall guards and own-process-only cleanup. Shared GPU isolation is not
  claimed by this worker.

Provider contract agreed with the Data agent
-------------------------------------------

The NEW physical producer is external `stage60_downstream_binding_v1`.
`FrozenDownstreamStore(manifest_path, expected_sha256)` opens actual bound
binary/source metadata and rejects incomplete/malformed annotation materialization.
`view(dataset_id, fold_id, role)` returns tuple dataset-local ordinals including
unready/unknown members; roles are `train`, `train_inner_validation`, `test`.
`get(dataset_id, ordinal)` returns an owned native sample; callers cannot freely
declare its source role. `contract(...)` returns tasks/units/output-level,
  train-only affine/availability, actual ordered UID membership and physical
  source/mask/geometry/readout bindings. `verify_unchanged()` rechecks all raw files.
  Every operation checks the actual protocol, original inventory and per-target
  units. Expansion units come from each frozen endpoint, never the dataset's
  prose label-space description. Role-to-UID lookup is checked once per training
  or evaluation operation, avoiding complete-role copies for every B32.

The consumer reads manifest.primary_cells, its actual239-primary/269-all-task
cell file and the physically bound historical_512_reference_bridge. It verifies
each actual384 readout config's canonical hash AND separate raw physical file.
Every endpoint report carries the exact original sample_set_sha256 and
label_mask_sha256 plus the cell-file reference and mask recipe. Runtime H0/batch/
prediction digests have separate domains and cannot replace those source oracles.

Expansion uses `fold_id='official'`, empty inner-validation view, original
train5326 ordinals followed by original test2282 ordinals offset5326. Original
side-local index, UID and order remain in source provenance. The other full
inventories are QM7 7165/QM9 133885/CYP2003/AZ109. The formal CLI cannot accept a
development subset as a full dataset. Cached features preserve all original
native rows/special H; no DEV AddHs Expansion cache or old512 readout hash is reused.

Resume and closure
------------------

Readout checkpoints contain actual readout config/state, complete AdamW moments,
source order/split/normalizer/cache/encoder binding, counters and Torch RNG.
Resume uses a fresh offline run with parent checkpoint/run lineage, validates
candidate states before copying, and continues the fixed20-epoch cursor. Success
keeps the small actual FINAL `latest.pt`; no BEST score selects the main model.
Errors retain `failed_state.pt` separately and cannot silently become resumable
success or rerun an acknowledged update. Epoch checkpoints remain actual prior
committed states. Any failed attempt must be explicitly reviewed by Root before
continuation; unsaved executed updates must never be replayed merely for telemetry.
