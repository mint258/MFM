## 4. 实验设计

### 4.1 阶段 0：描述符计算（纯 CPU，可先行）

1. **先测成本**：在分子大小、元素、复杂度有代表性的约 5000 个 TRAIN 分子上，分别测 L1、L2 的每分子 CPU 核秒、长尾耗时（p99）、失败率、有效字段数、输出字节。按实际唯一分子数外推，日报写一行。（量级参照：120 万分子 × 1613 个 float32 约 7.7 GB 原始稠密数值，缓存、mask、索引和临时峰值另算。）
2. **全量计算**：TRAIN、VAL 和 VAL 诊断分子，二维量每分子算一次。输入结构与现有 D20 的计算输入相同（同一规范化分子、显式氢、同位素、盐处理一致），固定软件版本和字段顺序。L2 只用 Mordred 二维模块，字段集合与 CheMeleon 的 1613 个对齐，并登记实际对应关系。区分"缺失"、"常数"和"真实的零"，缺失不填补。
3. **字段过滤（预注册规则）**：在 TRAIN 上去掉常数字段、有效率 < 95% 的字段、出现非有限值或数值溢出的字段。输出每个库的有序字段清单、去除原因和有效率。L1 中与 D20 同名的字段沿用 D20 的启用状态（桥头、螺原子保持禁用，MolMR 保持损失关闭）；L2 的字段不做跨库映射。
4. **新字段统计**：只用 TRAIN，按现行 D4 方法（q0.001/q0.999 缩尾估计均值和标准差，标签不截尾）拟合一次。现有 D20、D3 字段沿用原参数，不重拟合。
5. **下游特征导出**：对开发面板和基准线下游分子，用同一程序版本导出同口径的 L1、L2 特征（二维量不依赖几何；D3 组按基准线规定用 S′ UFF 构象），供第 5 节使用。
6. **交付**：manifest（store 引用、字段清单、统计参数、实际作业记账），STATUS 追加一条。验收由 D 窗口用真实 loader 加逐头过拟合测试完成；在此之前不算交付完成。

### 4.2 共同设置（阶段 1–3 所有臂）

- 训练设置与 S、P 相同：C1-0，每条运行从随机初始化开始，同 seed 共享初始化、抽样顺序和划分；FP32，TF32 关闭；B32；AdamW lr 3e-4、betas (0.9, 0.95)、wd 0.01；warmup 2%、cosine 到 0；每臂 60000–150000 样本窗口的 p99 裁剪；3M 筛选，每 1M 完整断点，每 500k 固定 VAL 记录。
- **损失块权重（预注册）**：把 D 损失分成三块：二维图标量、三维分子标量（D3 组的 6 个）、逐原子 SASA。以 D-R0 的现有设置为锚，冻结三块各自的总权重；块内按该样本实际有效项求均值。所有臂共享这一规则：换宽库只改变二维块内部的字段，不改变三块的总权重。宽库输出层的参数量和计算量另列报告。
- **目标截尾（预注册）**：三个库一律在损失计算时对标准化目标做 ±6 截断，存储值不变。每个字段报告被截断的 TRAIN 比例。这样三个库用同一预处理，差异不会来自截尾方式。

### 4.3 阶段 1：配方迁移（D-R0 对 D-R1）

| 臂 | 内容 | 回答什么 |
| --- | --- | --- |
| D-R0 原生基线 | D20 + D3 组，现有读出，不加 P 配方组件 | D 的原生基线；也是 9M 的基线 |
| D-R1 迁移配方 | 字段与 D-R0 完全相同，加入下面清单中的 P 组件 | P 配方整包迁移到 D 是否值得 |

**迁移组件清单（预注册，逐条记录"P 配置键 → D 字段/损失 → 对照值"）**：

- A1 元素参考：在 TRAIN 上用元素计数（含 H，加截距）对每个分子级标量做 5 折岭回归。折外 R² ≥ 0.999 的字段（几乎完全由组成决定，如分子量、价电子数）保留原目标，避免把接近零的残差放大成单位方差；0.30 ≤ R² < 0.999 的字段改为元素参考残差目标并冻结系数；R² < 0.30 的保留原目标。R² 在 ≥10 万分子上估计，统计误差远小于阈值间距。同一规则用于 L1、L2 的字段。
- B3 PMA 池化：用于全部分子级 D 标量的读出；逐原子 SASA 保持原子级头。
- B4：照 P 的既定设置和 γ 取值。
- P 第 4 轮或侧线胜出、且在 D 上有对应物的组件，按同样格式列出；P 专属的物理标签和额外前向（如扰动梯度）没有对应项，不迁移。

判定：D-R1 对 D-R0 按第 4.6 节规则。确认 WIN → 后续臂用迁移配方；否则用原生配方（记为"选定配方"）。结论只能归到整包，不能分给某个组件。如果判负、又需要定位原因，只在"待用户决定"里提议一项有诊断依据的单组件实验，不自行执行。

### 4.4 阶段 2：目标库与 3D 组（选定配方下并行）

| 臂 | 相对选定配方基线（D20 + D3 组）的唯一改动 | 回答什么 |
| --- | --- | --- |
| D-L1 | 二维块由 D20 换成 L1；D3 组、块权重、人群、几何不变 | RDKit 全集相对 D20 的净收益 |
| D-L2 | 二维块换成 L2，其余同 D-L1 | Mordred 集相对 D20 的净收益 |
| D-G1 去 D3 组 | 在 D20 上关闭全部 D3 组损失（6 个分子标量和逐原子 SASA），其余块权重不重新放大 | D3 组对下游的贡献；配合 CVF 看纯二维目标是否让构象信息消失 |

对照直接复用阶段 1 选中的那条运行（D-R0 或 D-R1，同 seed），不重训。L1 与 L2 不是嵌套关系，差异不能全部归因于字段数量；要证明"数量效应"需另做同一家族的匹配子集，本书不做。

**目标库选择（预注册）**：
- 宽库只有相对选定配方基线确认 WIN 才采纳。
- 两个都确认 WIN 时，用已有运行做 D-L2 对 D-L1 的配对比较（不需训练）：一方 WIN 则取它；TIE 则取计算成本较低的 L1。
- 都没胜出：保留 D20。

### 4.5 阶段 3：目标掩码（条件臂）

D-K1 只在采纳了宽库时跑：在被采纳的宽库上，每个样本随机屏蔽 85% 的有效二维损失项，三维块不变；块内按实际未屏蔽的有效项归一化；缺失 mask 与随机 mask 分开记录；某样本二维块全空时该块贡献为 0。对照为同库、同配方、无掩码的已有运行。只用 85% 这一个值。没有采纳宽库时不跑（D20 每分子只剩约 3 个有效项，结论无法外推）。

### 4.6 判定与种子（预注册）

全部照 `mfm-experiment-decisions` 与 p-recipe `protocol.json`，不另写：

- 主分 R3 七任务均值；R1 只报告；CYP 只报告。Δ = R3(候选) − R3(对照)，τ = max(0.01, 0.05 × 两者 R3 较大值)；分子级配对 bootstrap 1000 次，seed 20261025，95% 百分位 CI。WIN：CI 下界 > 0 且 Δ ≥ τ；LOSS：CI 上界 < 0（且未达 WIN）；其余 TIE（写"无显著改善"）。
- 删项臂 D-G1：只有 R3 的 CI 跨 0 才采纳去掉 D3 组；CI 整体 < 0 时保留。
- 只有 seed0 判 WIN 才补 seed1，对照的 seed1 只跑一次并共享。训练过程本身出问题的例外照项目规则。两种子逐个按原规则判定，都确认才采纳。

### 4.7 结果解读（预注册）

| 观察 | 结论 |
| --- | --- |
| D-R1 确认 WIN | P 配方整包可迁移到 D；后续用迁移配方 |
| D-R1 TIE/LOSS | 整包在 D 上无显著改善或有害；后续用原生配方，如实报告 |
| 宽库确认 WIN | 在块权重固定、同配方下，更大的二维描述符库带来净收益（不归因于"数量"本身） |
| 宽库都未胜出 | 保留 D20；报告"更大描述符库在本设置下无显著改善" |
| D-G1 的 CI 整体 < 0 | D3 组有贡献，保留 |
| D-G1 的 CI 跨 0，且 CVF 显著下降 | 去掉 D3 组按规则采纳；记录"纯二维目标使 3D 主干丢失构象信息"，供 SPD/MoE 设计 |
| D-K1 确认 WIN | 85% 目标掩码在宽库上有益，并入 D-final |

### 4.8 零训练诊断（只描述，不作采纳门槛）

在 D-R0、D-R1、采纳的配置和 D-G1 的 3M 终点各做一次：逐层 R1/R3、原子 H 与分子 mean(H) 的参与率、CEV/CVF/CVF_res。固定 5000 VAL 分子（seed 20261112），统计 F64，bootstrap 1000 次（seed 20261025）。复用已有前向，不做全层探针扫描。

## 5. 直接描述符对照（C1 的 D 部分）

目的：检验 D 预训练表示在"已知描述符"之外有没有增量价值。

- **开发面板（D 窗口执行）**：在七个开发任务上，对 D-final 的冻结 H0 做三组，共用任务划分和 TRAIN 内层调参预算：
  - A = 冻结 H0，R3 读出；
  - B = 同一套直接描述符（D-final 用的库 + D3 组，D3 组取开发面板规定的构象），两种读出：与 A 同容量的 MLP，以及基准线既定的 LightGBM；
  - C = H0 + 同一批描述符：描述符向量接在 R3 的分子级 MLP 输入处。
  - 另加最简参照：只用元素计数和重原子数，量化组成捷径。
  - 解读：A 优于随机编码器参照，说明预训练有效；C 优于 B，才直接支持"已知描述符之外有增量价值"；B 占优的任务如实报告。
- **最终基准（基准窗口执行）**：把采纳的库加入 C1 的 D 特征组（特征由阶段 0 导出，D3 组用 S′ UFF 构象），按基准线的冻结时点和协议执行。不能根据 C1 或 MFM 的结果改动已冻结的基准终点。

## 6. 验证位置（只在这里验证一次）

- 阶段 0 产物：分子 ID 对齐、字段顺序与清单一致、缺失与常数与零区分、新字段统计只用 TRAIN（由生产步骤验证）。真实 loader 加逐头过拟合测试（64 样本、冻结编码器只训新头、loss 降到初值 1% 以下）是唯一的接收验收。
- 逐原子 SASA 与源 atom ID 的对应。
- 块权重：三块总权重与 D-R0 一致；宽库臂中 D3 组的有效权重不随字段数变化（单元测试）。
- A1 规则的 R² 分档与冻结系数（由拟合步骤输出一次）。
- D-K1：开关关闭时逐位一致；掩码期望比例 0.85（容差按样本量的统计误差给出）；缺失 mask 与随机 mask 分开。
- checkpoint 与条件的对应。
