# S 配方研究：实现与运行说明

当前为准备阶段，科学预注册仍是 DRAFT；不含训练结果或采纳结论。任务权威为 [TASKBOOK.md](TASKBOOK.md)，起点为用户指定的已发布 p-recipe 提交 `49f1c6bc9d699085474fa86b7d5638a3c5231246`。

## 人群与输入

共同人群由一次生产步骤生成，见 `configs/s_recipe/population.json`：TRAIN 1,192,951，固定 VAL 5,000（seed 20261112），两侧允许构象上限均为 k=10。每个分子须同时具备已发布 PM7 和普通 S′ UFF 资格；排除已发布的323个重叠分子，不使用 P′ 资格代替普通 S′。另外1,277个 TRAIN 分子缺少一侧资格。保留11-07全 TRAIN 归一化，不重拟合。

`s_data.py` 只解码 MFM4 的元素、键和坐标，不解码物理标签。分子抽样 RNG 与构象选择分离；构象选择由 seed 和已消费样本序号确定，因此两种来源构象数不同也保持相同分子序列。预取只推进计划序列，断点只保存实际完成更新后的序列状态。

## 唯一改动

- S-B0：保留原三视图、PM7、坐标标准差0.1 Å。
- S-N1：每样本等概率选择0.05或√0.0175 Å，平均每轴方差0.01 Å²；不输入 σ，原噪声损失分母 `3×0.1²` 保持不变。
- S-N2：按严格转键逐次旋转一侧完整片段，得到 x_t，再加0.1 Å坐标噪声得到 y；预测目标是 y−x_t。扭转标准差为2度，来源为 [Frad 官方固定版本配置](https://github.com/fengshikun/Frad/blob/9972b8d80305acef0b381cbc4df5c6fe33c530ee/examples/ET-PCQM4MV2_dih_var0.04_var2_com_re.yaml)。坐标标准差遵循本任务书。无转键分子复用原基线噪声残差，保持精确回退。
- S-R1/S-R2：分别删去元素恢复/键级损失，仍除以原来有效角色数，保留其余项绝对权重。
- S-G1：仅将输入及去噪参照换为同一人群的 UFF；单种子描述，不合并、不做9M。

转键规则使用 [RDKit Release_2025_09_1 的 Strict3.1.0 定义](https://github.com/rdkit/rdkit/blob/Release_2025_09_1/Code/GraphMol/Descriptors/Lipinski.cpp)，在重原子图识别非环单键，并要求两端各有其它重原子邻居，再映回完整源原子顺序。

原始 native LMDB 当前路径已缺失。转键生产者使用原已关闭 WP5 population manifest 发布的 `formal_record_index.parquet`：由闭合 locator 按 `source_path + real_index + MID` 精确取原记录 SMILES，保留其形式电荷，再通过完整元素/键图匹配映射到 MFM4 原子顺序。只投影所需元数据列一次；不推断电荷、不复制原库、不生成新哈希、不写 `/tmp`。计划和绑定小表位于同一个 S 自有 SQLite，按批提交进度。

## 训练与恢复

`configuration.py` 只生成任务书预算和种子；`dispatch.py` 在 P 配方冻结且 P9M 已提交、S 预注册已冻结后才派发。3M 优先0–7号节点，9M优先20/22，缺合规卡时使用另一组；21禁用。普通 sbatch 按14个读取进程加2个控制核申请；20/22满足条件时支持同一任务 SSH→sbatch 完整状态接管，不申请 exclusive。

`s_training.py` 调用原 `s_model`、视图构建、原始三项 S 损失和裁剪校准；FP32、TF32关闭、B32、无累积或逐层重算。每个 seed 共用一个零训练随机初始化；3M和9M各自从头开始并按自己的预算做2% warmup和 cosine。

每1M发布不可变完整断点，包括模型、优化器、已消费样本及更新时钟、分子采样器、Python/NumPy/Torch/CUDA RNG、裁剪统计和配置。每500k固定 VAL 记录三项原始损失及相对零位移预测器的误差。验证前后保存/恢复训练 RNG。首个真实 S-B0 批次执行唯一基线接线验收；不另跑模型 smoke 或吞吐测试。真实前1000更新记录吞吐，全训练采样整卡功耗；使用现有真实离线 W&B SDK。

## 读出与判定

复用 `tools/p_recipe/evaluate.py` 的既有 R1/R3 协议及随机参照。S-B0的1M/2M/3M来自同一3M日程；其它运行读取各自终点。GPU生成一份闭合H缓存并执行原R3；原R1岭回归与1000次MID bootstrap在CPU8–19执行，结果只写 S 目录。

`s_statistics.py` 消费生产者保存的共同 bootstrap 抽样，不重新回读预测体或另做 bootstrap。R3七任务均值为主分；WIN为CI下界>0且 Δ≥τ，LOSS为CI上界<0，其余TIE；τ=max(0.01,0.05×两者较大R3)。R1和CYP只报告。种子、删项例外、合并和最终9M严格遵循冻结后的预注册；当前两处文字澄清尚未解决，不执行采纳或冻结。
