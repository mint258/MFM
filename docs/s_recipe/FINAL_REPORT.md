原筛选、规定诊断、两条原9M确认及E1/C1/C2科学工作均已闭合：有效预训练预算63M，192/192个完整微调拟合、16/16个评测点、13/13项登记配对比较。全部拟合已封存选中编码器、头和归一化，原预测与失败记录保留；完整来源见[评测交付](FULL_FINETUNING_PROGRESS.md)。本报告已补齐科学结果与固定截止成本；最终回归和PR状态见末节。

## 研究问题与预注册

本研究在固定C1-0主干下检验噪声尺度、扭转采样、元素恢复、键级预测和几何来源。执行依据为[TASKBOOK](TASKBOOK.md)及用户的[E1](USER_DIRECTIVE_20261123.md)、[全量微调](USER_DIRECTIVE_20261123B.md)、[scaling](USER_DIRECTIVE_20261123C.md)补充指示。分支起点为用户指定的p-recipe提交`49f1c6bc9d699085474fa86b7d5638a3c5231246`；科学注册在`configs/s_recipe/preregistration.json`。

本线预训练只使用元素、键和坐标，不读取QM或物理计算标签。不引入力目标、DeNS、额外损失权重、第二轮筛选或参数扫描。下游带标签的冻结读出和完整微调属于评测。原筛选规则与E1的明确k*规则分别执行，补充微调不改原配方判定。

## 数据与训练定义

共同TRAIN为1,192,951个同时具备已发布PM7和普通S′ UFF资格的分子；剔除已有323个重叠分子，另有1,277个TRAIN分子缺少一侧资格。固定VAL为5,000个分子，seed为20261112。保持11-07全TRAIN归一化，不按子集重拟合；人群对应和泄漏检查由原人群生产步骤完成，见[方法与原始来源](METHODS.md)。

主干为d=512、6层、8头、FFN=2d。B32/micro32，FP32，TF32关闭，不累积梯度、不做逐层重算。AdamW学习率3e-4、betas=(0.9,0.95)、weight decay=0.01；每条运行按自身预算进行2% warmup和完整cosine退火。先均匀采分子，再在允许构象中均匀采一个；同seed共享零训练初始化和分子顺序。

裁剪初值281.7，各臂独立使用60k–150k窗口每步裁剪前范数的p99，随后固定；不借用其它运行的阈值。每1M保存完整状态，每500k记录固定VAL的三项S损失及位移预测相对零位移预测器的误差。恢复保持模型、优化器、采样位置、随机状态和裁剪状态；失败尝试与有效运行分开保留。

| 臂 | 唯一改动与依据 |
| --- | --- |
| S-B0 | 原三视图，PM7，笛卡尔坐标噪声σ=0.1 Å |
| S-N1 | 每样本等概率取σ=0.05或√0.0175 Å，平均每轴方差仍为0.01 Å²；不输入σ，不改原损失分母3×0.1² |
| S-N2 | 先沿严格可旋转键旋转一侧片段得到x_t，再加0.1 Å坐标噪声得到y；预测y−x_t；无转键时精确退回原噪声 |
| S-R1 | 只关闭元素恢复损失，其余绝对权重和原有效角色分母保持；三视图仍生成 |
| S-R2 | 只关闭正键五类键级预测损失，同样不重新分配其余权重 |
| S-G1 | 在共同人群上将PM7几何与去噪参照换为普通S′ UFF；单种子描述性对照 |

S-N2的扭转标准差为2度，来自[Frad固定版本配置](https://github.com/fengshikun/Frad/blob/9972b8d80305acef0b381cbc4df5c6fe33c530ee/examples/ET-PCQM4MV2_dih_var0.04_var2_com_re.yaml)。可旋转键按[RDKit Release_2025_09_1 Strict3.1.0](https://github.com/rdkit/rdkit/blob/Release_2025_09_1/Code/GraphMol/Descriptors/Lipinski.cpp)在重原子图上识别非环单键，两端各有其它重原子邻居，再映回源原子顺序。源形式电荷、拓扑与原子对应的既有绑定及无转键比例、分层去噪描述见[METHODS](METHODS.md)与原臂交付；不重新识别或抽样。

## 评测与统计口径

所有正式R1/R3固定第6层H0，即`encode_atoms`输出。主分为七任务R3均值，R1和CYP只报告。逐层读出仅在S-B0、不同的S-final和S-G1三个3M终点进行，层6复用正式结果；PR/CEV/CVF/CVF_res使用规定5000 VAL、F64和原分子抽样。诊断不选最佳层、不作采纳门槛，见[B0](B0_ENDPOINT_DIAGNOSTICS.md)、[final](FINAL_ENDPOINT_DIAGNOSTICS.md)、[G1](G1_ENDPOINT_DIAGNOSTICS.md)。

Δ为候选减对照，τ=max(0.01,0.05×两者较大的R3)。以分子为单位配对bootstrap 1000次，seed=20261025，报告95%百分位CI。WIN需CI下界>0且Δ≥τ；LOSS为CI上界<0；其余TIE。没有多重比较校正。删项WIN须两个预训练种子各自确认；TIE仅CI跨0时采用简化，CI整体负或LOSS保留。多个兼容采用项须按注册条件做S-M1。

完整微调沿P既有四任务协议：qm9.U0_atom、qm9.homo、exp.LogD、exp.LogS，种子0–2；编码器全部可训练，逐原子MLP后聚合，保持源原子顺序。训练集内seed=20261112划出10%作选择集；AdamW编码器lr=1e-4、头lr=1e-3，betas=(0.9,0.999)，wd=0.01；B32、FP32、TF32关闭，5% warmup后50轮cosine，按选择集MAE选最好一轮。原同协议12个scratch拟合直接复用。

原单位MAE和相对scratch改善均报告。三种子分数均值与“三种子平均预测的分数及CI”是不同估计量，分别列出；E1专用真实seed-mean抽样CI。完整结果及原生产者路径见[微调进展](FULL_FINETUNING_PROGRESS.md)、[逐种子表](../../results/s_recipe/full_finetune/rows.csv)和[配对比较](FULL_FINETUNING_CONTRASTS.md)。未重新拟合原预测或重抽bootstrap。

## 局限与成本

本研究的分子CI条件于已训练模型，不覆盖预训练种子变异；没有多重比较校正，TIE也不是等价或非劣性证明。PM7优化几何隐含外部物理信息，不能把本线解释成完全无物理先验；共同分子与相同构象上限也不使PM7/UFF构象分布完全相同。开发面板与最终统一UFF基准存在几何差异。3M的构象结论和删项结果不能无条件推广到更长预算，9M负结果及描述性完整微调应同时报告，不据单次观察写机制结论。

注册有效预训练预算63M已完成：六条3M筛选、两条原9M、三条新增E1 3M和两条子集9M；失败尝试不混作有效预算。16个不同检查点组的192个完整微调均已完成，重复来源只计一次，原12个scratch拟合直接复用。15段实际RAM完整状态暂停与4段模型前准入失败原样保留；正常原生75接管另列，不混入RAM暂停，不把缺失退出码补成0。真实首1000步吞吐与整卡功耗点见[运行元数据](EXTENSION_STARTUP.md)，不外推整段能耗。
