## 1. 背景与已有结论（直接引用，不重测）

- 现行 S（`current/phychem_mfm/phase1/v3_structural.py`）有三个视图：σ = 0.1 Å 各向同性笛卡尔坐标去噪；元素恢复，只对实际被改动的原子计损失；正键上的五类键级分类。基线直接复用这套实现，新噪声只改几何视图。
- 历史量级（只作参照，人群、预算、目标版本都不同，不直接比较）：P0-S（24 万分子、6M）R3 ≈ 0.471、R1 ≈ 0.208；M2（全量 P、3M）R3 = 0.4680、R1 = 0.2975。旧 S 的原子 H 参与率约 3.41、分子 mean(H) 约 2.08，S 末层不塌缩。旧 S′ 实验提示训练不足，但不能凭此给所有 S 臂加预算。
- P 研究的方法不迁到 S：A1 元素参考和 B3 PMA 池化作用于分子级标量目标，S 没有这类目标；B4 针对 P 的表示谱塌缩，S 不塌缩。P 上判 TIE/LOSS 的方向（学习率、字段加权、head 变体、共享投影器等）只说明"在 P 上无显著改善"，本线不据此下结论，也不重开。
- 配方线 X1（去掉 xTB 扰动梯度及其额外前向）R3 Δ = −0.01639，CI 全负，按规则保留原组分。它不能单独说明 xTB 梯度替代 S 去噪的价值，属于混合阶段的问题。
- 已知混杂：在 PM7 优化几何上做去噪隐含了物理优化信息，纯 S 不能宣称完全不含外部物理。S-G1（UFF 几何）用来量化这一差异。

## 4. 实验设计

### 4.1 共同设置（除非臂本身改这一项）

- 主干 C1-0（d = 512、6 层、8 头、FFN 2d），每条运行从随机初始化开始；同 seed 的候选与对照共享初始化、分子抽样顺序和划分。FP32，TF32 关闭。
- B32（microbatch 32，单次前向，无梯度累积，关闭逐层重算）；AdamW lr 3e-4、betas (0.9, 0.95)、wd 0.01；warmup 2%，cosine 按各运行自身预算退火到 0。
- 采样：先均匀选分子，再从允许的构象中均匀选一个。
- 梯度裁剪：前 150000 样本用沿用 P 协议的初值，取 60000–150000 样本窗口每步裁剪前范数的 p99，之后固定到结束。每臂各自算，阈值写入运行目录，只报告不调参。
- 预算：**筛选 3M**；每 1M 存完整断点，每 500k 在固定 VAL 上记录三项 S 损失和"预测位移相对零位移的误差"。
- **共同人群**：所有 S 臂（包括 S-G1）只用同时有 PM7（S）构象和 UFF（S′）构象的 TRAIN 分子，两侧每分子允许构象上限取相同的 k，按数据线现行清单确定。Root 开训前生成一次人群清单 `configs/s_recipe/population.json`，日报写一行分子数和 k。这样 S-G1 与 S-B0 是同一人群上的配对比较，不需要另补 PM7 对照。
- 删项臂（S-R1、S-R2）中，其余损失项保持原来的绝对权重，**不自动重新归一化**；若实现会自动重分配，先显式固定。

### 4.2 S-B0：基线

现行三视图、σ = 0.1 Å，PM7 几何，3M，seed0。开训前在真实训练入口确认一次：损失分母、三个视图的目标绑定、源原子顺序（这是本线唯一的基线验收，用真实 loader 和真实训练本身完成）。

1M、2M、3M 断点各跑一次 R1/R3，只作预算趋势记录。这些是同一条 3M cosine 运行的快照，不是 1M、2M 预算下的结果。若有理由认为预算会改变候选排名，日报"待用户决定"提议一组基线与候选**同时**延长的匹配日程；不给单个候选单独加预算。

### 4.3 筛选臂（第 1 轮，也是最后一轮）

| 臂 | 相对 S-B0 的唯一改动 | 回答什么 |
| --- | --- | --- |
| S-N1 多尺度噪声 | 每个样本以等概率取 σ ∈ {0.05, √0.0175 ≈ 0.1323} Å，平均每轴噪声方差与 σ = 0.1 Å 相同；目标仍是原始位移，损失标度与其余两项权重不变，不把 σ 作为输入 | 在平均噪声强度不变时，噪声尺度的多样性是否有益 |
| S-N2 Frad | 先对可旋转键做扭转得到 x_t，再加 σ = 0.1 Å 坐标噪声得到 y；去噪目标为 y − x_t（与原 S 头"预测所加位移"的约定一致）；元素恢复、键级视图不变 | 沿低能扭转方向采样构象、只对坐标噪声去噪，是否优于纯各向同性噪声 |
| S-R1 去元素恢复 | 只关闭元素恢复损失；输入采样、噪声、其余权重、读出不变 | 元素恢复的边际贡献 |
| S-R2 去键级预测 | 只关闭正键五类键级分类损失 | 键级预测的边际贡献 |
| S-G1 S′ 几何 | 输入几何与去噪参照由 PM7 换为 UFF；目标与配方不变；共同人群 | 同人群、同配方下几何来源的差异（PM7 几何混杂的量级） |

**S-N2 的冻结定义**（写入预注册）：
- 可旋转键：源拓扑上的非环单键，两端各至少有一个其他重原子邻居；用 RDKit 严格可旋转键规则判定，规则版本写入预注册。键的识别按源原子顺序一次性预计算（CPU 节点），训练时只查表。
- 扭转幅度：采用 Frad 官方发布配置中的单个扭转噪声设置，记录来源仓库版本、数值和角度单位；不扫参。如果改用本项目自定的值，要在第一个样本之前写明并把该臂标为"Frad 变体"。
- 没有可旋转键的分子：只加 σ = 0.1 Å 坐标噪声（即退回 S-B0），分子保留。日报写一行这类分子的比例。
- 按可旋转键数（0、1–3、4–7、≥8）分层报告去噪误差，只作描述。

不做的变体：显式 σ 条件化、改损失权重、Frad 再叠加多尺度、SliDe（需要内坐标势参数和切片目标，是独立的研究问题，见不做清单）。

### 4.4 判定与种子（预注册）

判定、τ、bootstrap、种子规则全部照 `mfm-experiment-decisions` 与 p-recipe `protocol.json`，不另写：

- 主分：R3 七任务均值；R1 只报告，不触发补跑；CYP 只报告。
- Δ = R3(候选) − R3(S-B0)，τ = max(0.01, 0.05 × 两者 R3 较大值)；以分子为单位的配对 bootstrap 1000 次，seed 20261025，95% 百分位 CI。WIN：CI 下界 > 0 且 Δ ≥ τ；LOSS：CI 上界 < 0（且未达 WIN）；其余 TIE（写"无显著改善"）。
- 删项臂（S-R1、S-R2）：只有 R3 的 CI 跨 0 才采纳去掉；CI 整体 < 0 时保留原组分。两个删项臂各自 TIE 也不推出可以同时删除。
- 只有 seed0 判 WIN 的臂才补 seed1；对照复用一条 S-B0 seed1（发布为 `S_B0_SEED1_REFERENCE.json`，只跑一次）。训练过程本身出问题的例外照项目规则。两种子仍按原规则逐个判定，都确认才采纳。
- S-G1 是描述性的几何对照，**不参与配方合并**，单种子；按上面的规则报告 Δ、CI 和判定。

### 4.5 合并与冻结（预注册）

- S-N1、S-N2 互斥。两者都确认 WIN 时，保留 Δ 较大者；两种子平均 Δ 相差小于 τ 时取 S-N1（更简单）。
- 互不排斥的确认胜出项（一个噪声臂，和/或采纳的删项）只有一个时，直接组成 S-final。有两个及以上时，跑一条 3M seed0 合并运行 S-M1，与 S-B0 配对：WIN 则 S-final = S-M1；否则 S-final 取单项中 Δ 最大者（删项按"采纳去掉"计）。
- 没有胜出项：S-final = S-B0，如实报告负结果。
- 所有臂有最终判定后发布最终 `configs/s_recipe/CURRENT_BEST.json`，`status` 写明冻结，日报记一行。冻结前不提交 9M。

### 4.6 结果解读（预注册）

| 观察 | 结论 |
| --- | --- |
| S-N1 确认 WIN | 当前设置下，平均强度不变时噪声尺度的多样性有益 |
| S-N2 确认 WIN | 扭转采样加坐标去噪的 Frad 方案有益；分层结果只作描述 |
| 两个噪声臂都 TIE/LOSS | 保留 σ = 0.1 Å，报告"本主干与数据下噪声设计无显著改善" |
| S-R1 或 S-R2 的 CI 跨 0 | 去掉该辅助任务，简化 S 配方 |
| S-R1 或 S-R2 的 CI 整体 < 0 | 该辅助任务有贡献，保留 |
| S-G1 的 CI 不含 0 且 \|Δ\| ≥ τ | 记为 PM7 几何混杂的证据（方向如实报告），供 E2 解释 S 与 S′ |
| S-G1 TIE | 当前预算下几何来源无显著差异；不能写成"等价" |

### 4.7 零训练诊断（不训练，只描述，不作采纳门槛）

在 S-B0 和 S-final（若不同）的 3M 终点、以及 S-G1 上各做一次：逐层 R1/R3、原子 H 与分子 mean(H) 的参与率、CEV/CVF/CVF_res。固定 5000 VAL 分子（seed 20261112），统计 F64，bootstrap 1000 次（seed 20261025）。S-N1 额外按 σ 分组报告标准化去噪误差。直接复用已有前向，不做全层探针扫描。

## 5. 验证位置（只在这里验证一次）

- 共同人群清单：分子 ID 与两侧构象的对应、与 323 剔除清单和下游泄漏规则一致（由生成清单的步骤验证）。
- 新噪声模块：开关关闭时与原实现逐位一致；S-N1 两档等概率、每轴方差与 0.01 Å² 相符（容差按样本量的统计误差给出）；S-N2 扭转只改变一侧刚性片段、键长不变（|Δ| ≤ 1e-6 Å 且相对 ≤ 1e-6），目标符号和单位按实际原子顺序核对；无可旋转键分子正确回退。
- 删项臂：其余损失的绝对权重与 S-B0 一致。
- checkpoint 与条件的对应：由训练生产者写入运行目录，评测时按此绑定。

吞吐不另做测速测试：真实训练前 1000 步记录样本/秒。S-N2 若低于 S-B0 实测的 70%，先优化向量化或预计算索引（不改噪声数学），日报记一行，继续。

- 不加 A1、B3、B4 或其他 P 配方组分。
- 不给单个候选单独延长预算；不跑第 3 个种子，不在种子规则外补 seed1。
- 不改其他线的分支和文件，不改 `docs/paper/`、归一化参数、划分或判定规则。
- 不对已有结果做二次回读或独立复核；中间步骤不写收据和哈希。
- 不停止、迁移在跑的训练；不用付费服务器，不申请 exclusive，不删除文件。
- 结项后不再占用 GPU。
