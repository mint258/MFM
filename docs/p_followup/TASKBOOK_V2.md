### 数据与表示

- 分子：固定 5000 个 VAL 分子（diagnose.py 的 validation_indices，D6 FULL，k=10）。组成分析取每个分子的第一个允许构象；构象分析取全部允许构象（≤10 个）。
- 层：第 3–6 层。第 6 层是 encode_atoms 的默认输出（经过 out_norm）；第 3–5 层用 return_intermediates，与 D5 一致。
- 落盘只保存每条构象各层的 mean(H)（F32，用完删除）。原子级 H 不落盘，只流式累积按元素分组的统计量。

### 指标（全部用 F64 计算）

组成特征 X_c：D4 元素参考基底中各元素的原子计数、总原子数、重原子数。大小特征 X_n：只取总原子数和重原子数。

| 指标 | 定义 |
| --- | --- |
| CEV | mean(H) 的组成解释方差比。对 512 维做多输出岭回归 H ~ X_c：5 折按分子划分（seed 20261025），α 在训练折内从 {1e-3, …, 1e3} 中按 10 倍步长选取；CEV = 1 − Σ_d SSE_d / Σ_d SST_d，用折外预测计算 |
| CEV_size | 同上，特征改为 X_n |
| PC_k R² | mean(H) 前 3 个主成分各自对 X_c 的折外 R² |
| EEV | 原子级 H 的元素间方差 / 总方差（各维求和） |
| CVF | 有 ≥2 个允许构象的分子上，mean(H) 的分子内方差 / 全部构象记录的总方差 |
| CVF_res | 分子内方差 / 组成残差的总方差。组成残差 = 构象级 mean(H) 减去该分子的 X_c 折外预测 |
| 目标参照 | 对同一批记录，用各条件实际训练的归一化 P 分子级标量目标算 CEV 和 CVF，逐字段计算后按字段方差加权；只纳入有效率 ≥99% 的字段，缺失按字段剔除。C、D 用各自的字段集合和目标定义 |

不确定性：按分子做 1000 次 bootstrap（seed 20261025），条件之间做配对 bootstrap。bootstrap 重抽的是固定的折外残差，不在每次重抽内重新拟合回归。

## 工作 B：大数值能量字段的 F64 补存

设计：按 D6 记录顺序对齐的 F64 sidecar，只覆盖少数选定字段；loader 增加一个默认关闭的开关。不改 MFM4 格式，不重写或复制 LMDB，不重拟合 D4/A1（F64 与 F32 原值之差不超过 1 ulp，对 center 的影响远小于 scale 的 1e-6）。

### B0 字段选择（预注册，不读新数据）

范围：109 个启用字段中的 43 个分子级字段里的标量。数据：冻结面板 TRAIN 核心构象对及原 F64 缓存。对每个源非零差的构象对，计算：

- e = |(f32(a) − f32(b)) − (a − b)|（字段原单位）；
- r = e / |a − b|。

满足以下任一条件即入选：

- 中位 r > 1e-4，且中位 e / s_j > 1e-6（s_j 为 11-07 D4 scale）；
- 源非零对被压成零的比例 ≥ 0.1%。

预期入选 r83、r460、r499、r670，以规则计算为准。r41、r54 即使入选，也因 C 的去除而不再使用，sidecar 中仍按规则收录。

输出：每个字段的中位 |raw|、中位 |Δ|、中位 e、中位 r、归零比例、是否入选。这张表也是 D0 的噪声下限来源。

### B1 生成 sidecar

1. 范围：D6 full compact 中携带入选字段的全部记录，覆盖全部 split（含 P′ 记录，若 D6 中有）。
2. 读取：通过物理索引和原组件读取器流式读出 F64 值。
3. 写出：按 D6 记录顺序对齐，列为 molecule_index、conformer_index、D6 id_map 中的稳定句柄，以及各入选字段的 F64 值（mask 无效时为 NaN）。另写 manifest。
4. 写出时的一次性对齐检查（唯一一次）：每条记录必须满足 f32(sidecar 值) 与 D6 存储值逐位相同，NaN 必须对应 NaN。
   - 不一致的记录写 NaN，loader 回退到 F32 原值，并计数；
   - 某字段不一致率超过 0.01% 时，该字段整体不启用，记为 UNRESOLVED。
5. 先用前 1% 的记录实测吞吐，更新总耗时估计。

## 工作 D：分子级目标的构象分解（侧线臂，3M）

### D0 分解定义（预注册）

基底是 C（去冗余后的 99 个字段）。D 与 C 的配对比较只反映分解的作用；D 与 M1 的差值另外报告，供主线比较。

记号：分子 m 的允许构象集合为 K_m，即采样器实际使用的 k=10 允许构象；字段 j 在 A1 元素参考扣除后的值为 y′。

| 量 | 定义 |
| --- | --- |
| μ_mj | 分子在 K_m 上有效构象的 y′ 均值（F64） |
| t1（分子目标） | (μ_mj − c1_j) / s1_j，同一分子的所有构象相同 |
| t2（构象偏差） | (y′_mcj − μ_mj) / s2_j；只有 1 个有效构象的分子 t2 记为无效 |
| c1_j、s1_j | 在 TRAIN 上对 μ_mj 拟合的均值与标准差 |
| s2_j | 在 TRAIN 上、有 ≥2 个有效构象的分子中，(y′ − μ) 的均方根 |

入选分解的字段需同时满足：

- 属于 C 字段集合中的分子级标量；
- TRAIN 上有 ≥2 个有效构象的分子占 ≥50%；
- s2_j ≥ 1e-3 × s1_j（相对），且 s2_j ≥ 10 × e_j（绝对；e_j 为 B0 表中的中位 F32 构象差误差）。

不满足条件的字段保持 C 的原目标。原子级字段与向量字段不变。

loss：入选字段 j 的 loss = ½ × (MSE(t1) + MSE(t2))，字段在等权平均中的总权重与 C 相同。头部：H1 对入选字段输出 2 个数（t1、t2），来自同一个 pooled 向量。还原公式：y = A1 参考 + c1 + s1·t1 + s2·t2，用于 VAL 原单位 MAE。

### D1 拟合与均值表

- 对 D6 全部分子（全部 split），从现存 F32 值（转 F64）计算 μ_mj，存成按 molecule_index 对齐的均值表，同时记录 molecule_id。c1、s1、s2 只用 TRAIN 拟合。
- 均值表生成时的一次性检查：随机抽 1000 个分子（seed 20261025），经 p_recipe_data 的实际 read 路径逐构象读出 y′，重算 μ，要求 \|差\| ≤ 1e-9 + 1e-9 × \|μ\|（F64）。这是均值表与分子身份对齐的唯一验证。
- 输出：入选字段表（每个字段的有效构象分子占比、s1、s2、s2/s1、s2/e_j、是否入选）、参数文件、均值表（不进 Git）。
- 资源：CPU 按需 ≤16，估计 ≤6 h；磁盘 ≤1 GiB。

### D2 实现与验收

- 配方新增 conformer_decomposition（参数文件路径），在 p_recipe_data.py 生成 t1/t2，并在 original_predictions 中还原。
- 单元测试只覆盖新逻辑：
  - 分解与还原：y 与还原值之差 ≤ 1e-9 + 1e-9 × \|y\|（F64）；
  - 单构象分子的 t2 为无效；
  - 头部输出维度。
- 真实使用验收：用实际 loader 取 64 个 TRAIN 样本，对 t1、t2 各头做 overfit 测试（只训头部，编码器冻结，≤2000 步）。每个头的 loss 降到初始值的 1% 以下即通过；未通过的字段按总规则 6 退回不分解。
- 配置：configs/p_followup/D_decomposition.json，以 C_dedup.json 为基底，只增加 conformer_decomposition 及运行名/路径相关键。
- 启动：D0–D2 完成后，在符合准入的空闲卡上启动。

### D3 评价

- R1/R3 与 C3 相同。
- 主要比较 D 与 C（配对）；同时报告 D 与 M1 的配对差值。
- 描述性报告：VAL 上同分子构象差的原单位 MAE（按字段，D 对 C）；A 的 CEV、CVF_res（对应 A-H6）。

## C/D 判定与采纳规则（预注册）

判定沿用主线规则：R3 配对 95% CI 整体 > 0 为 win，整体 < 0 为 loss，其余为 tie。

| 臂 | 比较 | 结果 | 建议 |
| --- | --- | --- | --- |
| C | 对 M1 | win 或 tie | 去冗余作为主线下一轮新启动运行的默认字段集合（用户已原则批准去除；tie 时按更简洁的标签集合采纳） |
| C | 对 M1 | loss | 不采纳，如实报告 |
| D | 对 C | win | 作为分解候选交主线，与第 2 轮各臂一起参与下一步 M 判定（用 D 对 M1 的差值），规则与 B1–B4 相同 |
| D | 对 C | tie 或 loss | 不采纳 |

两点约束：

- 所有“建议”都要经用户确认后才并入主线。并入只对之后新启动的运行生效，已在跑或已完成的运行不改、不重跑。
- 若主线基底因 A4 等原因变化，C、D 的结论保留为“M1 基底上的证据”，按用户已授权的 B 证据处理方式重新判定其有效性，不自动重跑。
