## 2. 新增 D′：在当前最优配方上做构象分解（直接启动，不等 D）

- **配置**：由 `round3/M2.json` 复制，只加 `conformer_decomposition` 和运行名/路径相关键。执行键保持与 M2 相同。
- **字段**：沿用 D1 已有的均值表和已经入选的 33 个字段，**不重算 D1**。C 的去冗余已判为 loss、不采纳，所以 D′ 使用 M2 的完整 109 个字段；去冗余时去掉的那 10 个字段在 D′ 中保留原目标，不分解。
- **验收**：D2 已在同一套分解实现上通过逐头验收，D′ 只换了基底。所以只为新组合写单元测试（PMA 下分解头的输出维度；开关关闭时逐位一致），**不重复逐头验收**。
- **对照**：直接复用配方线的 M2 3M。
- **判定**：
  - 单种子满足 |Δ| ≥ 0.06 且 CI 不跨 0 时直接判定；
  - 否则补跑 D′ seed 1，对照的 seed 1 **复用配方线的 M2 seed 1 运行**，本线不另跑；
  - 补跑后，两个种子的 CI 下界都 > 0、且平均 Δ ≥ max(0.03，M2 两种子平均 R3 × 8%) 判胜；两个种子的 CI 上界都 < 0 判负；其余为持平。
