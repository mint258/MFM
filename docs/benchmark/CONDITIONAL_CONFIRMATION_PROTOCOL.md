# Conditional downstream confirmations

The one B1 screen freezes all96 original endpoint decisions. Plans are generated only from a significant neural improvement entering retained/appendix results; traditional ML has one seed. Original1H sample-redo confirmation4537338 is mandatory independently of its eventual role and is reused rather than dispatched again.

Dispatch binds exact original dataset/task, learner, feature group and native producer configuration. A task name alone cannot identify a dataset. Closed task metadata supplies this binding; scientific scores are not reread to check earlier calculations. Ambiguous or absent bindings stop that new consumer for repair. prepare_job_source runs on CPU, retains original frozen25 folds and primary population, preserves50-epoch/64-batch Chemprop or the official TabPFN recipe, and uses neural model seed20261026 with split/statistics seed20261025.

New seed2 predictions must preserve the candidate's exact original TEST observation IDs, labels, complete InChIKeys, folds, native-feature missingness and actual TRAIN arithmetic mean. Only their first report statistics and newly required paired contrasts are computed. Confirmation comparisons reuse registered seed20261025 control predictions; they disclose the candidate's seed20261026. No extra control seed is trained merely to support a comparison.

C1 primary scores remain copied from the provisional report. Final results show separate seed1/seed2 rows, actual fit sizes and original native-feature coverage. A second seed that fails to reproduce significance is labeled explicitly; the frozen role remains. Actual terminal failures are UNRESOLVED with original source evidence. Pending confirmations cannot be called final. The final C1 table alone gets its SHA; provisional tables, seed plans, per-seed supplements and new code do not.

final_results_export.sbatch is prepared and unsubmitted. Its BENCHMARK_CONFIRMATION_EVIDENCE_JSON must point under the shared B1 artifact root to the closed actual confirmation consumer manifest: status CONDITIONAL_CONFIRMATION_REPORT_CLOSED, terminal native accounting, enforced original TEST binding, the same frozen B1 roster and C1 primary manifest, and B1/C1 evidence records keyed by original configuration. finalize_c1/finalize_baseline_confirmations enforce exact required-plan coverage before export. The export copies primary estimates and frozen decisions; it does not perform a second screen or independent numerical QA.

Source templates that still contain checkpoint-download calls are refused by GPU preparation. Resolve their existing official checkpoint paths on a CPU node first; do not execute environment setup on a GPU host. This applies in particular to the older original PharmaBench TabPFN source template, whose classifier-weight acquisition was embedded in its CPU producer. Its existing closed files should be reused only when the corresponding actual conditional plan requires that source.

Each generated plan now includes primary_source_job, primary_native_jobs and primary_source_folders copied from the actual closed prediction consumer. For scaffold repetition arrays, the source identity is the original native array parent and the child identities are retained separately. A configuration cannot mix unrelated native producers. This lets dispatch disambiguate identical source task names without rereading old scientific scores.
