# Joung 光学任务的固定输入与划分

原始九终点、20,236 条观测和 B0 适用域标记保持不变。目标值直接读取原列，不换单位、不平均重复观测。输入按发色团与溶剂的角色区分；溶剂是实验条件，小溶剂不会按目标分子的重原子下限另行剔除。

| 方法 | 固定输入 |
|---|---|
| RF-ECFP4 | 发色团与溶剂各 r=2、2048 bit，按角色拼接，再加 is_gas |
| LightGBM-RDKit2D | 两个组分的原始 RDKit2D 描述符及 is_gas |
| Chemprop v2 | 官方 MulticomponentMPNN；两个独立默认 300 维 / depth3 消息传递块，各自 mean 聚合；默认 FFN 接 600 维拼接与 is_gas |
| C1 D | 原生发色团 D26，加同一溶剂 RDKit2D 条件及 is_gas；LightGBM / TabPFN |

原始 `Solvent=gas` 的 19 条观测是明确气相条件。原生空溶剂图没有化学原子，其 Morgan 指纹自然为空；Chemprop 官方空图接口和显式相标记已通过测试。空图下未定义的 RDKit 描述符保留 NaN，原生发色团 D 的缺失不填补。不生成溶剂构象，也不把水等其他分子代入气相条件。全部 20,236 条原始观测现在都有相应输入。

划分在任何本任务拟合前冻结：5 次重复 × 5 折 Murcko scaffold 划分，同一发色团 scaffold 的全部溶剂观测保持在同一折，非环状发色团共用 ACYCLIC 组。原始冻结折成员在气相条件接入后直接复用，统计按完整发色团分子分组。主结果不使用随机逐行划分。

模型使用默认或官方配置、seed 20261025，不搜参。Chemprop 的每个端点以数组 index0–4 对应原定五次重复，每个子作业跑该重复的五折；统计消费者要求汇齐完整 25 折，才运行 Tukey HSD 和 B1 规则。拆分作业没有增加重复或种子。实际作业与环境选择见 [原生执行索引](../../workflows/benchmark_evaluation/native_jobs_20261120.json)。
