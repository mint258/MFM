## 1. pKa

- **主任务：分子级宏观 pKa。**
  - 每个分子取最强酸性跃迁、最强碱性跃迁各一个值，作为两个终点（酸、碱）。只有一类跃迁的分子，只进对应终点。
  - SAMPL6、SAMPL7 作外部盲测，按 B0 已建立的 `dataset + rawdataID` 关联；SM 编号必须连同挑战名一起使用。盲测分子从训练集剔除，按完整 InChIKey 判断，剔除记录写入清单。
- **机制任务：原子级 pKa，只用单电离位点的分子。** 这类分子的宏观值等于该位点的值，位点可以唯一指定。
- **多位点分子不做微观分配。** pKahub 中预测得到的 microspecies 不当作实验微观 pKa。
- 先在日报里写一行：宏观、微观各有多少记录，多位点分子有多少，单位点子集有多少。单位点子集过滤后不足 30 个点时，按 §2.1 降为附录。

## 2. NMR

- 采用 **nmrshiftdb2-2018 标准划分**：Jonas & Kuhn 2019 发布，Kwon 等 2020 沿用。¹³C、¹H 分别作为任务。
- 优先使用原文发布的划分文件。拿不到时，按原文描述的规则（种子、比例、单位）重建，并在结果表里注明"重建划分"。这是 NMR 唯一需要核对的地方：划分后的测试集分子数与原文对得上。
- 引用的文献数字只取同一划分上的结果。CSTShift 使用自己的 NMRShiftDB2-DFT 测试集，并把 DFT 屏蔽张量作为输入，只作为"带 DFT 输入的参考上限"列出，不算同条件比较。
- HOSE 码照 §3.1b 引用文献数字。

## 3. 下游构象与 P 标签

- **不重建 PM7 优化流程。** 预训练 S/P 用的 PM7 几何来自上游旧数据，优化流程没有记录；现在重建出来的不是"同一流程"，不符合 §4.4。
- 所有 3D 模型（我们的模型和所有 3D 基线）在下游统一用 **S′（UFF）构象**，原指示里写"用 S 构象"的地方一律改为 S′。
- C1 的 P 组用 **P′**（UFF 几何上的 PM7/xTB 单点），字段与预训练 P′ 相同。结果表标注"P′"，不写成 P。
