# 等变性验收规则 v2

依据用户 2026-10-29 的明确修订，自本版本起采用以下规则。原规则、原失败记录及原始数组全部保留；历史结果的 v2 复判另行记录，不回写旧结果。

| 精度与用途 | 验收规则 |
| --- | --- |
| FP64 数学正确性 | 相对误差 ≤ 1e-9 |
| FP32 数值验收 | 对每个输出元素检查 `abs(actual-reference) <= 1e-6 + 1e-4*abs(reference)` |

比较对象仍是原始物理变换后的参考输出：标量不变、矢量随原旋转矩阵变换，其他原张量继续沿用原登记的变换律。保持全部原案例、种子、视图、字段、单位和变换；不能按新结果删案例或重采样。

FP32 必须使用每个元素的真实参考幅值，不能用总体最大绝对误差推断通过。报告逐字段/逐案例结果、最大绝对误差、门限比例及有限值检查；错误或缺少数组单独报告。

FP64 的原始相对误差定义、参考和零值处理必须在复判产物中明确；缺少足以证明该规则的数据时记为未证实，不能拿 FP32 结果或局部算子结果替代完整模型的数学正确性。

本修订只针对等变性验收，A 类前向/梯度对照仍使用其独立规则。本轮不新增 FP32 补偿诊断；所有该类候选继续按[归档决定](FP32_COMPENSATION_ARCHIVE_20261029.md)不采用。

[工作节奏](OPERATING_POLICY.md)：每日一份汇总，每周记账；正式产出保留必要的收据和 SHA。

本次复判将 FP64 相对门明确为逐元素 `abs(actual-reference) <= 1e-9*abs(reference)`，不加分母 epsilon。参考值为0时，仅差值也为0才通过；同时报告原有范数相对误差（若有），不混同两种指标。原记录若只有最大绝对误差而无逐元素参考，则该部分记为未证实。
