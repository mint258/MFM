# D-1 / D-2 / D-4 模型侧审阅需求（草案）

2026-10-25。当前尚未收到双方共同冻结的 D-1；本文件是模型线需求清单，
**不是 training_format_v3.md 的替代品，不宣告任何真实字段/路径/统计已经存在**。

| 交付项 | 需要明确的内容 | 对实现/验收的影响 |
| --- | --- | --- |
| D-1 分子/构象身份 | 稳定 molecule ID、conformer ID、TRAIN/VAL 角色、固定构象顺序、最低能构象 ID、多样性顺序与各版本来源 SHA | 保证先抽分子再抽构象；最低能/多样性清单不由模型推断 |
| D-1 几何来源 | PM7 与 S′ UFF 的记录定位、每构象可用性、逐分子混合选择、坐标单位、几何和标签所对应的物理状态 | 混合来源不能隐式切换标签或把 PM7 几何上的矢量当作 S′ 的矢量 |
| D-1 原子和原子对对应 | native atom 顺序/显式 source atom IDs、原子数、pair 索引方向/重复/顺序、元素编码、是否含氢 | H0 原子顺序和逐原子/逐对标签必须完全对应；不按名称猜索引基数 |
| D-1 字段形状与类型 | graph/atom/pair 层级、标量/完整三维矢量/模长、float64 源值到训练 fp32 输出的明确约定、分类整数域 | 当前模型侧只接收已解码的 fp32 原单位连续标签或 long 类别，不自行转换实际存储 |
| D-1 有效性与暴露 | 每字段 bool validity、逐分子 S/D/P mask、逐分子 family mask、科学失败/缺失/物理越界的显式规则 | 无效标签不得用 0 冒充；监督暴露不得改动原标签或 actual_corruption 事实 |
| D-2 注册表 | 稳定字段名、所属 S/D/P 和 family、单位、广延/强度、pooling、向量/模长、类别数、Huber 特例 | 同字段跨标签组合共用头和归一化；未注册字段直接拒绝 |
| S 与新 pair 物理标签 | 旧 S RDKit 正边五分类与连续 Wiberg 的独立身份；旧元素温度/平滑/L2 配方；新 S 字段的显式 role binding | 旧 S BondPairHead 与原分类损失保持；不能把连续 Wiberg 默默阈值化来替代它 |
| D-4 归一化 | TRAIN-only fit 人口/版本、每字段中心和尺度、稳健统计定义、不可用字段、能量元素参考系数及原子编码 | 标量用固定 TRAIN 变换；能量参考作为显式预测偏置，不重写标签 |
| D-4 矢量归一化 | 零中心和同方向尺度，或等价且明确的保持旋转对称方式 | 逐方向不同尺度/固定非零方向中心会破坏几何等变，需要双方先解决 |
| D-3 节点本地导出 | 每节点物理路径、文件清单/大小/SHA、只读标志、局部文件系统证明、provider 句柄生命周期 | provider 的 node_local 声明本身不是现场本地读取证明；吞吐/等待占比需实测 |
| D-5 子集与两类验证 | 12万⊂24万⊂60万⊂全量清单，以及已见分子未见构象的具体排除/角色规则 | 未见分子与未见构象的指标分开；不能编造角色或仅凭 ID 文本推断 |
| 版本变更 | 双方共同冻结 v3.0 的提交号；任何后续 schema/field/mask/order 修改升版本并说明影响 | 检查点与缓存通过接口/数据 SHA 拒绝跨版本静默恢复 |
