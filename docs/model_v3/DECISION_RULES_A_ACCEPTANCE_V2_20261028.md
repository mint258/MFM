# A 类梯度验收规则 v2：逐元素混合容差与解析零梯度

2026-10-28。状态：用户已批准的 v2 规则；本文件的 GitHub 公开提交构成预登记。只有公开提交完成后，才可按 v2 重新验收 A5。本文不授予任何新的实验 PASS。

## 修订原因与旧结果

A5 / GPU 4524601 在旧 v1 规则下仍为失败。20 批前向通过；六层距离偏置 MLP 末端 bias 的 120 项梯度比较未通过旧逐参数相对 L2 门，实测最大绝对差为 9.506493370281532e-10。该项失败及原始记录全部保留，不回写为通过。

数学上，解析梯度恒为零时，以该梯度为分母的纯相对误差无定义。旧实现使用 max(reference_norm, 1e-12)，因此产生的是有定义但被近零数值残差放大的数值比值；不把旧实测分母误写成程序实际除零。v2 改用用户指定的混合容差，并对解析零梯度另加双边范数门。

## v2：所有参数均逐元素检查

令 a 为候选梯度，b 为参考梯度。每个参数张量中的每个元素都必须满足：

    abs(a - b) <= 1e-8 + 1e-4 * abs(b)

atol = 1e-8，rtol = 1e-4，比较是逐元素的，不是逐张量 L2 相对误差，不按参数或层选择容差。b 始终是参考实现。任何一个元素失败，该参数与该固定批次的梯度门都失败。

对已由实际模块结构和数学语义证明解析梯度恒为零的参数，还必须同时满足：

    norm(a, 2) <= 1e-8
    norm(b, 2) <= 1e-8

此附加门不能仅由“实测梯度很小”推断适用对象。当前既有 S / 六层注意力实现中的距离偏置末端投影 bias，要按实际 Parameter 身份、确切名称、层数、头数和 softmax 共同加数语义登记。未证明的参数仍检查通用逐元素混合门，不能擅自列入解析零集合。

两侧都无梯度的已停用头保留原合法规则；单侧缺失、参数集合或形状不一致、非有限梯度均失败。不得通过删除参数、清零梯度、替换模型或改变参考方向获得 A 类通过。

校验中的差值、范数和计数可以用 FP64 累积，模型与训练的原精度策略不因此改变。报告保留每批、每参数的形状、有限性、违规元素数、最大误差/阈值比、双边梯度范数及解析零适用依据；不以总平均掩盖局部失败。

## 保持原有的其他门槛

- 固定 20 个原批次的全部浮点前向输出：原相对 L2 误差 <= 1e-5。
- 同一种子 500 次更新：每个记录点的 loss 相对差 <= 1e-3。
- 原参数、输入顺序、采样器、视图/噪声/掩码、损失、优化器、种子、确定性控制和数据/代码来源不变。
- 三卡的单项与叠加、R1 吞吐与容量、完整日志/同步仍各自验收。
- 物理等变性仍为原 FP32 绝对 atol=1e-5、rtol=0；B 类曲线包络与 RMSE <= 2% 等原门槛不变。

## 独立 C 类候选：删除冗余 bias

按用户要求，在独立 C 类架构候选中，把距离偏置投影到注意力头的最后一层设为 bias=False，覆盖经源码确认具有同样共同加数语义的实现。默认/历史路径保持；该改动不混入 A5 或其他 A 类重验收。

该 bias 在实数 softmax 方程中是每头共同加数，因此是冗余参数。实现须保留其余参数与初始化随机流，明确减少的 Parameter/state 键、公共参数映射和新的配置/检查点身份。实数等价不能替代实际 FP32 数值与物理测试；删除参数后的候选也不能继续冒用原完整参数哈希或旧验收证书。
