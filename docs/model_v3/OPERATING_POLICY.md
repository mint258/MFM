# 模型线工作节奏

2026-10-29 起按用户最新要求执行，覆盖旧的逐动作报告、逐作业记账及层层收据做法。

- 每天维护一份汇总：`DAILY_YYYYMMDD.md`，同日更新同一文件，记录实际结果、未完成事项和下一步。
- 成本账本每周更新一次，保留真实 Slurm 作业记录。最新历史账本 v54 为已有时间点快照，不为每个短任务再生成新账本。
- 收据和 SHA 用于正式产出、正式发布与必要的来源身份；日常查状态、读源码、机械修改不再生成独立收据、哈希包或审核层。
- 运行仍走真实 Slurm，CPU 至少16核并采用已批准的自动内存；GPU 保留 UUID 公共锁、实际空闲核/内存检查、RSS/输出/配额保护。减少文书不取消运行保护。
- 当前优先级：等变性 v2 复判；归档全部 FP32 补偿；真实 S 上的 C1-a 吞吐和显存测量。C1-a 工程测量不等待 D-5。
- 工程性能结果不替代 S/P 开发面板的科学选择，不构成模型/配方冻结或正式预训练授权。
