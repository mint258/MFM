## 修订 1：选型只跑单种子

阶段 5、阶段 6、潜变量实验和 M4 的所有选型都只跑 seed0，不再给前两名补 seed1。多种子只用于主线 E2 的正式训练（每个条件 2–3 个种子，具体数目由用户在 E2 前决定）。

**新的两候选判定规则**（替代原“相差不超过一个种子标准差”）

1. 对候选 A、B，在主指标的每个格子上取归一化改善之差，等权平均得 Δ = Δ(A−B)。跨条件的决策（如 C1 的 S/P）先在各条件内算 Δ，再按条件等权平均。
2. 置信区间：沿用面板的按分子组配对 bootstrap（1000 次，seed 20261025）。同一次抽样同时用于 A、B 和所有格子，直接得到 Δ 的 95% 区间。
3. **A 胜出**当且仅当：Δ 的 95% 区间下界 > 0，且 Δ ≥ max(0.01, 0.05 × max(score\_A, score\_B))。
4. 不满足即为平局，按既定简单性顺序选：C1-0/a/b、两/三视图、H1/2/3、原架构/加潜变量模块。运行耗时只在同类 GPU 上可比时参考。
5. 多于两个候选时，按 Δ 主指标排序，用上述规则比较第一与第二；平局则在二者中按简单性选。

**M4 的 B\* 平台规则同步修改**：样本数翻倍后，若开发主指标改善 < max(0.01, 5% 相对)，或翻倍前后的 Δ 区间包含 0，就取翻倍前的样本数。B\* 仍取 S/P 两者较大值。64M 仍只是观测上限，未观察到平台时如实记为未定。

这两条规则在任何新分数产生前记入 `DECISION_RULES_TASKBOOK_V2.md` 末尾的修订记录，注明“用户 2026-11-10 批准”。`followon_templates.json` 中的 seed1 模板保留但不再使用。

## 修订 3：Lite 分子潜变量模块的实现规格

新增文件 `current/phychem_mfm/model/v3_latent.py`，在 `ArchitectureOptions` 中加 `latent` 选项：`none`（默认，原架构）、`pma`、`lite`、`lite_rec`、`dense_addon`。默认值下代码路径与现在完全一致。以下超参数全部固定，写入配置，不做扫描（唯一例外见下一节的 λ/k 两档）。

**记号与固定取值**：d = 512，h = 8；k = 8 个潜变量，维度 d\_l = 256；只在骨干第 5、6 层插入；d\_z = 64，d\_s = 64；d\_dec = 256；λ = 0.1。潜变量初值 Z₀ ∈ ℝ^{8×256} 按 N(0, 0.02²) 初始化。

**每个插入层**（放在该层原子自注意力和 FFN 之后）：

```
读：  Z ← Z + MHA(Q = LN(Z)W_Q, K = LN(X)W_K, V = LN(X)W_V) W_O
      Z ← Z + FFN_l(LN(Z))                  FFN_l: 256 → 512 → 256
自注意：Z ← Z + MHA(LN(Z), LN(Z), LN(Z))      注意力矩阵 8×8
写：  X ← X + γ ⊙ MHA(Q = LN(X)W'_Q, K = LN(Z)W'_K, V = LN(Z)W'_V) W'_O
      γ ∈ ℝ^{512}，初始化为 0
```

读出中 softmax 对原子维归一化，padding 位置在 softmax 前加 −∞。所有结构视图都经过潜变量层；预测头和重建只用干净视图。

**分子表示**：

```
z_lat = vec(Z⁽ᴸ⁾ W_p)                             8 × 64 = 512 维
g_i   = σ(LN(x_i) w_g + b_g)                      不归一化的逐原子门控
z_sum = (1/N_ref) Σ_i g_i · LN(x_i) W_s           64 维，N_ref 为 240k 子集的平均原子数
z     = [z_lat ‖ z_sum ‖ log N]                  577 维
```

**预测头路由**（只按注册表已有的池化方式分配，不新增字段决定）：

- 注册表池化为 mean 的分子级字段：ŷ = MLP\_f(z)。
- 注册表池化为 sum 的分子级字段：ŷ = Σ\_i MLP\_f(x\_i) + w\_fᵀz，其中 w\_f 初始化为 0。
- 原子级字段：照旧读 x\_i。
- 结构自监督头：照旧。

**重建目标**（只在 `lite_rec` 下启用）：

```
q_i   = E_elem[Z_i] + RBF_32(‖p_i − p̄‖) W_r        只含元素和到质心的距离
X̂     = FFN(CrossAttn(Q = q, K = V = (Z⁽ᴸ⁾ W_p) W_up)) W_out
L_rec = (1/N) Σ_i ‖x̂_i − sg(x_i⁽ᴸ⁾)‖² / v̄       v̄ 为 sg(X⁽ᴸ⁾) 的逐维方差均值
L     = mean_{启用组}(L_g) + λ · L_rec          λ 在所有条件下相同
```

解码器只能看到 Z⁽ᴸ⁾ W\_p，不得接触 X。

**各选项的内容**

| 选项 | 潜变量层 | 写回 | z | L\_rec |
| --- | --- | --- | --- | --- |
| `pma` | 无；只在最后一层后做一次读 + 自注意 | 无 | 有 | 无 |
| `lite` | 第 5、6 层 | 有 | 有 | 无 |
| `lite_rec` | 第 5、6 层 | 有 | 有 | 有 |
| `dense_addon` | 无；第 5、6 层各加一个原子级残差 MLP，参数量与 `lite_rec` 相差不超过 5%，输出门控初始为 0 | — | 无 | 无 |

**验收**（只测新增逻辑，数学正确性按 FP64 门槛）：

1. 从任一 C1 检查点加装 `lite_rec`，γ = 0 时 X⁽ᴸ⁾ 与原检查点相同，容差 max(1e-7 绝对, 1e-6 相对)。
2. FP64 下打乱原子顺序和施加随机旋转平移后，z 的相对范数误差 ≤ 1e-9。
3. padding 位置不改变 z 和有效原子的 X，容差同第 1 条。

FP32 下的不变性误差只报告，不判通过与否。真实训练的第一次运行就是接线验收，不另加冒烟。计算量估计：在骨干注意力与 FFN 的基础上增加约 10%，解码器另增约 3%，参数增加约 2.6 M。

## 潜变量模块实验

三层实验全部单种子，都从 C1 胜者出发，在 S 和 P 两个条件下各做一遍，数据仍是原 240k 子集。所有结果都用 v2 面板评价。对带 z 的模型，分子级任务另加两种读出：R1z（ridge 读 z）和 R2z（与 R2 同超参数的 MLP 读 z）；R1/R2/R3 则照常读原子表示 X。SoM 只读 X。

**第 0 层：冻结骨干，只训练读出**

目的是定量“平均池化丢了多少信息”。从 C1 胜者的 S、P 6M 检查点出发，骨干全部冻结：

1. T0-1：原模型，直接引用修订 2 中的 R1/R2/R3 结果，不重算。
2. T0-2：\[mean ‖ sum/N\_ref ‖ max ‖ std\] 四统计量特征，不训练，评 R1、R2。
3. T0-3：只训练 `pma` 读出。P 条件用 P 的分子级字段；S 条件没有分子级目标，只用 L\_rec。
4. T0-4：只读不写的潜变量（读 + 自注意、第 5–6 层输出上、无写回）加 L\_rec。

T0-3/T0-4 各训练 0.5M 样本，只更新新增参数；AdamW lr 3e-4、betas (0.9, 0.95)、2% warmup + 余弦、B32、clip 1。共 6 次短训练。本层只报告结果，不作门槛，完成后直接进入第 1 层。

**第 1 层：配对续训（主要检验）**

从同一 6M 检查点出发，每组再训练 1.5M 样本。优化器重新初始化：2% warmup 到 lr 1e-4，再余弦衰减到 0；其余配方与 C1 运行相同。新增参数与骨干用同一学习率。

| 组 | `latent` 选项 | 用途 |
| --- | --- | --- |
| A0 | `none` | 原架构同样续训，扣掉额外训练带来的收益 |
| A1 | `pma` | 可学习读出单独的作用 |
| A2 | `lite` | 骨干内双向交换的作用 |
| A3 | `lite_rec` | 完整方案 |
| A4 | `dense_addon` | 同参数量对照 |

共 10 次续训。S 条件下 A1/A2 的 z 只能从已有的梯度路径得到训练，这是设计上的预期结果，不要补目标。

**预注册的比较**（都用修订 1 的规则，S/P 等权）

1. **主比较**：A3 的 R2z 对 A0 的 R3。各自按预期的使用方式比较。
2. A3 的 R2z 对 A4 的 R3，排除参数量的影响。
3. 分解：A1 R2z 对 A0 R3；A2 R2z 对 A1 R2z；A3 R2z 对 A2 R2z。
4. 信息保留：A3 的 R3（读 X）对 A3 的 R2z。
5. A3 的 R1z 对 A0 的 R3：线性探针能否追平深读出。
6. SoM 两格单独报告：A3 对 A0，均读 X，取 R2。

**采用规则**

- A3 采用条件：比较 1 和比较 2 都判 A3 胜出，且 SoM 平均改善不低于 A0 超过 max(0.02, 10% 相对)。
- A3 未通过但 A1 通过同样的三条条件（以 A1 替代 A3）时，采用 A1。
- 都未通过：保持原架构，如实记录，进入阶段 5 剩余决策。
- A3 被采用时，再补 2 档：λ = 0.3（k = 8）和 k = 16（λ = 0.1），各 S/P 共 4 次续训。与默认档按修订 1 规则比较，平局保留 λ = 0.1、k = 8。

**机制分析**（只报告，不作门槛）：对 A0 和 A3 的 P 条件检查点，在开发面板的 TRAIN 分子上用 RDKit 计算数据线已有的 28 类固定 SMARTS 官能团是否存在。分别从 mean(H) 和 z 做逻辑回归探针（与 R1 同样的 5 折选正则），按重原子数 ≤20、21–35、>35 三档报告 AUROC。不读 TEST。

**第 2 层：从头训练确认**（只在第 1 层采用了 A3 或 A1 时进行）

- 被采用的方案加上选定的 λ/k，按 C1 运行完全相同的协议从随机初始化训练：240k、6M、seed0、原配方，S 和 P 各 1 次。
- 与 C1 胜者已有的 6M 结果比较（新模型 R2z 对原模型 R3），用修订 1 规则。新模型胜出则模块进入冻结配置；平局或原模型胜出则按简单性顺序保持原架构，两层结果都如实记录，并在日报第一行写明，由用户决定是否另行处理。
- 只报告的小规模完整微调：用两个 P 条件检查点，在 LogD、HLM CLint、homo 三个任务上更新编码器微调。新模型用 R2z 头，原模型用 R3 头；编码器 lr 1e-4、头 lr 1e-3、30 轮、seed 0，只用 TRAIN 内层评价。不参与任何决策。

## 之后的阶段 5、阶段 6/M4 与冻结

科学顺序和网格沿用 v2 任务书，只做以下调整：全部单种子；所有决策使用 v2 面板和修订 1 的规则；所有配置都带上潜变量实验的结论（下文称“选定架构”，即 C1 胜者加上被采用的 `latent` 选项，或 `none`）。主指标对带 z 的架构是 R2z，对 `none` 是 R3。

1. **C3 视图数**：两/三视图 × S/SDP，使用选定架构。三视图 S 若与已有运行的全部科学配置相同，直接复用。
2. **预测头 H1/H2/H3** × P/D/SDP，使用选定架构与视图。H1/P、H1/SDP 按原复用规则引用已有运行。带 z 的架构里，头形式只改变各字段 MLP 的结构，输入路由保持修订 3 不变。
3. **池化**：潜变量实验采用了 `lite_rec` 或 `pma` 时，原“注册表/可学习池化 × P”比较取消，由潜变量实验代替；保持 `none` 时按原计划进行。
4. **M4 配方**（240k，S/P）：
   - 五个学习率 × S/P，B32；
   - 前两个学习率在 B64 重跑；
   - 最佳学习率下比较余弦与 WSD（最后 20% 线性衰减）；
   - 裁剪阈值取 TRAIN 裁剪前梯度范数的第 99 百分位数；
   - 最后用 SDP 确认一次。
5. **全量 S/P 与 B\***：用 D6 正式 TRAIN 1,194,551 个分子，保留 64M 调度预算，在 1/2/4/8/16/32/64M 分段取开发读数，每段恢复优化器、RNG 和样本时钟。B\* 按修订 1 的平台规则确定。
6. **冻结**：产出模型配置和配方配置两份 `status=FROZEN` 文件、代码标签，并补全 `PREREG_round1.md` 和 `HANDOFF.md`。

已有运行的复用规则、分段计数、执行微批（只改执行、有效批不变）、磁盘保护和恢复协调器全部沿用 `M3_M4_CONTINUATION.md`。
