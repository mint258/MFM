# C-only bias-free distance-to-head projection

This is a source-only, opt-in architectural candidate in `MFM_model_v3_C_bias_free_candidate_v1`, on the Root-created branch `model-v3-c-distance-bias-free-20261028-v1`, based on local `e4b21193be60fcb396ab1d2d56c1cba6736078dd`. It is distinct from A gradient acceptance v2, all old performance methods, and every existing numerical/physical result. None is replaced or retroactively qualified by deleting a parameter here. No CPU/GPU or scientific adoption result exists for these new bytes.

## Accurate removal scope

Set `backbone.distance_bias_projection_bias=False` explicitly. Omission means True and never inserts the key into an old configuration. Explicit True retains the old parameters, construction and arithmetic. The opt-in full encoder is the original six-layer512/eight-head C backbone with distance bias enabled and original H0 shape512. Numerical modes, geometry, QKV/FFN implementations, heads, epsilon, masks, and original parameter initializers remain as configured; this flag does not select another numerical candidate.

For C1-0, each DenseGeoSelfAttention distance MLP is `Linear(1,dim) -> SiLU -> Linear(dim,nheads)`. Remove only the last per-head bias in each of its six layers: exactly six `dist_mlp.2.bias` vectors, 48 scalar parameters in total. The final actual Linear has `bias=None`, exposes no bias Parameter, and emits no corresponding state-dict key. It is not a hidden frozen/zero-valued parameter.

For C1-a/b, each SharedPairAttention `pair_projection=Linear(pair_dim,nheads,bias=False)` was already bias-free. The new configuration validates and records that existing property across all six layers; no additional parameter is deleted. In particular, retain both biases in `pair_encoder.project`. Those parameters live in pair-feature space and are multiplied by an optional distance-dependent cutoff envelope before the per-head projection. They are not unconditionally common logit constants. C1-0 decreases by48; C1-a/b decrease by0.

## Initialization and mathematical boundary

Dense still constructs the original Linear with its original bias, in the original module/parameter initialization order, then calls `register_parameter('bias',None)`. The existing local Linear initializer zeroes biases; keeping the exact construction sequence preserves its random stream and every other same-seed parameter rather than reseeding or assuming a different initializer's RNG consumption. The constructor adds no random draw. Shared projection construction was already bias=False and remains unchanged. No other Parameter object is replaced, and no persistent buffer is added.

Over the admissible-key population, a scalar per head that is independent of query/key adds a common softmax constant. Its real softmax derivative in that direction is zero, and the real distribution is invariant. This is not a promise of FP32 bitwise equality: removing a fused affine bias can change floating-point operations and rounding. The actual implementation retains finite `-1e9` masking rather than replacing it by an ideal mathematical negative infinity; no statement of exact real equality for arbitrary unbounded logits/sentinel conditions is made. No mask, cutoff, radius, all-masked convention, or initialization amplitude is changed. Actual C physical tests must still retain the full48 cases,192 FP32 forwards,13 fields by3 transformations,52 terminals per case, original nonzero/domain/unit controls, and absolute `1e-5, rtol=0`.
