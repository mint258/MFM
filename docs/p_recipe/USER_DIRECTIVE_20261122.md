## 2. 组成信息诊断（零训练，预注册）

- **断点：** T2 和 T1 各取 1M、3M、6M、9M，共 8 个。T1 的中间断点按 11-21 指示的读出顺序完成后再做。
- **工具与设置：** `tools/p_followup/collapse_composition.py`，第 6 层 H0（原子 H 与分子 mean(H)），固定 5000 个 VAL 分子（seed 20261112），统计用 F64，以分子为单位 bootstrap 1000 次（seed 20261025）。不做其他层。
- **报告的量：** 每个断点上 mean(H) 与原子 H 的 CEV（组成解释方差）、CVF、CVF_res、参与率，以及 CI。
- **预注册假设 H-comp：** T2 的 mean(H) CEV 从 1M 到 9M 下降，而且下降幅度大于 T1。
  - 支持：T2 的 CEV(9M) − CEV(1M) 的 CI 上界 < 0，且该变化与 T1 同一变化之差的配对 CI 上界 < 0。
  - 不支持：T2 的变化 CI 下界 ≥ 0，或者 T2 与 T1 之差的 CI 下界 ≥ 0。
  - 其余：不确定。
  - 同时并列 U0 的逐任务 R3 走势（来自第 1 节），只作描述，不进判定。
- 不论结果如何，冻结配方都不变，不据此新增臂、训练或 seed。
