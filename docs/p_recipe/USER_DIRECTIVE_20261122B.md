## 0. 为什么做

现有结论（R3 约 4M 后饱和、分子数无显著作用、B4 拉低 U0、P 优于 P′）全部来自冻结编码器的读出，而且读出训练本身的随机性不在现行 CI 里。本指示要回答：这些结论在微调下是否成立，读出噪声有多大，B4 是否确实压缩了组成信息。

## 1. 已知事实（只列本指示用到的）

- 冻结配方 A1+B3+B4+F2。T2（9M）R3 峰值 6M 为 0.491，9M 为 0.4775；R1 从 0.200 升到 0.376。T5/T6/T2（25 万/50 万/119 万分子）9M 的 R3 为 0.467/0.481/0.4775。
- B4 = 0.1 × [relu(γ − 每维 std) 的均值 + 维间相关平方的均值]，γ ≈ 0.16，固定权重（`p_recipe_training.py` 第 107 行）。第 2 轮 U0 的 R3：M1 0.636、+B4 0.532、+B3 0.676；第 3 轮 M2 0.621。
- R3 读出：逐维标准化，AdamW 恒定 lr 1e-3，30 轮，读出种子 0。开发面板 QM9 约 7,372 个训练分子、2,048 个评测分子，ExpansionRx 约 3,800 个训练分子（各含 10% 选轮次留出）。

## 3. F：微调评测（最高优先级）

### 3.1 协议（预注册，固定不改）

- **四种评测方式，读出头相同，只差可训练部分：**
  - frozen：冻结编码器，即现行 R3；
  - top2：只解冻最后 2 层编码器和读出头；
  - full：全量微调；
  - scratch：随机初始化编码器加全量训练。它是微调的对照基线，用同一套超参。
- 读出头与现行 R3 相同（逐原子 MLP 后聚合）。H0 输入保持源原子顺序。
- 划分：开发面板原划分。评测集与 R3 相同；早停集为训练集内按 seed 20261112 打乱后的 10%（与 R3 的 `internal_epoch_selection` 一致）。
- 优化：AdamW，编码器 lr 1e-4，读出头 lr 1e-3，wd 0.01，betas (0.9, 0.999)；批 32，FP32，TF32 关闭；前 5% warmup，之后在 50 轮内 cosine 到 0；按早停集 MAE 选最好的一轮。
- 种子：每个配置用微调种子 0、1、2，报告均值和标准差，判断以三种子均值为准。
- 指标：每个任务的原单位 MAE；以 scratch 为参照的归一化改善 (E_scratch − E)/E_scratch；同时给出相对随机编码器 frozen 读出参照 E_ref 的分数，方便和 R3 对齐。CI 仍用以分子为单位的配对 bootstrap，对三种子平均后的预测计算。

- 第 2 轮 M1、B4、B3 和第 3 轮 M2 的 3M 断点，做 full，同样 4 个任务、3 个种子，看 B4 对 U0 的伤害在微调下是否还在。
- T4 9M（P′）做 full，与 T2 9M 配对，看 P 对 P′ 在微调下的差距。

### 3.4 预注册解读

| 观察 | 结论 |
| --- | --- |
| full 下 T2 9M 的均值相对 4M 前的断点仍有超过 τ 的提升，而 frozen 没有 | 平台期主要是冻结读出的限制，表示仍在改善 |
| full 下也约 4M 后不再提升 | 平台期是表示本身的性质，不是读出造成的 |
| full 下 T5/T6/T2 的差显著大于 frozen 下的差 | 分子数的价值要靠微调才体现 |
| full 下 B4 对 U0 的伤害消失 | B4 只是让信息不易被冻结读出取用，没有真正丢掉信息 |
| full 显著优于 scratch | 预训练在微调下有效；报告各任务改善幅度 |

τ 照现行规则：max(0.01, 0.05 × 两者较大值)，在 scratch 参照的归一化改善上计算。

## 4. A：零训练检查

### A1. 读出噪声（与 F 第一批并行）

- 断点：T2 的 1M、6M、9M，round4 F2 的 3M（冻结配方的 3M）。
- 每个断点再用读出种子 1、2、3、4 各跑一次 R3（种子 0 已有），共 16 次读出。报告每个任务及七任务均值的五种子均值、标准差，以及标准差与 bootstrap 半宽之比。
- 若七任务均值的读出种子标准差 ≥ τ/2（约 0.012），在"待用户决定"里提议今后改用多种子读出（改判定口径是停止条件，不自行执行）。

### A2. B4 是否压缩组成信息（预注册 H-B4）

- 断点：第 2 轮 M1、B4、B3，第 3 轮 M2 的 3M 断点。工具 `tools/p_followup/collapse_composition.py`，第 6 层 H0，固定 5000 VAL 分子（seed 20261112）。报告 mean(H) 与原子 H 的 CEV、CVF、CVF_res、参与率。
- 支持：CEV(B4) − CEV(M1) 与 CEV(M2) − CEV(B3) 的 CI 上界都 < 0。不支持：两者 CI 下界都 ≥ 0。其余：不确定。与 H-comp 并列报告。

### A3. B4 惩罚项的实际大小

- T2 的 1M、3M、6M、9M，在固定 VAL 上前向，分别报告 B4 的铰链项、去相关项，以及 0.1 × B4 与 P 总损失之比。只作描述。

### A4. 上限对照（不新算）

- D 线第 5 节在开发面板上的结果出来后，把 T2 的逐任务 R3 与直接描述符、组成参照放进同一张表，标出 R3 不如它们的任务。

### A5. P 与 P′ 在同一下游几何上（只限 ExpansionRx 三项）

- T2、T4 的 9M，ExpansionRx 三项改用基准线已封存的 S′ UFF 构象作输入，按完整 InChIKey 精确对应；没有 UFF 几何的成员从两边同时剔除并报告数量。报告 T2 − T4 的配对 Δ 和 CI。QM9 保持 DFT 几何，不做此项。

### A6. 下游标签数（QM9）

- 从 QM9 fold 0 的 TRAIN 部分，按开发面板同一规则（分子组按 SHA256([20261025, dataset, group]) 排序）取前 30,000 个分子组作读出训练集（是现有 8,192 的超集）；评测集仍是原来的 2,048 个。只用 TRAIN 角色，不碰任何测试集。
- 对 T5、T6、T2 的 9M 和随机编码器做 frozen R3（读出种子 0），只做 QM9 四项。报告分子数的作用在 7 千和 3 万个下游标签下是否不同。
- 时间盒：物化这 3 万个分子超过 4 小时或连续失败 2 次，记 UNRESOLVED，本项跳过。
