# 配方线补充指示：E1 构象数 k*（用户 2026-11-23）

适用：P 研究。冻结配方 A1+B3+B4+F2 不变（I1 是否采纳另行决定，本项不受影响）。k=10 参照为 round4 F2 的 3M seed0 运行。本线 k* 写入 `configs/p_recipe/E1_k_star.json`。

## 1. 决定（用户 2026-11-23，即主线决策 D4）

E1 压缩为：只用全量分子（与本线现有 3M 筛选同一人群），每分子允许构象数 k ∈ {1, 2, 5, 10}，用本线已冻结的配方，各 3M、seed0。不做分子数维度（P 的 T5/T6/T2 已覆盖），不做"最低能量"或"多样性"选构象的变体，不做 D。

## 2. 设置

- **选构象：** 每个分子按数据集卡（`docs/data_v1/DATASET_V1_CARD.md`）已保存的构象固定随机秩，取秩最小的 k 个，所以 k=1 ⊂ k=2 ⊂ k=5 ⊂ k=10。可用构象不足 k 的分子保留全部，不复制、不补足；日报记一行每格的实际平均 k。D-5 诊断构象照旧先排除再选。
- **采样：** 照现行规则：先均匀选分子，再在该分子的前 k 个构象中均匀选一个。
- **实现：** 新增一个默认关闭的开关（每分子构象上限 k，按固定随机秩截取）。开关关闭时与现行逐位一致；只测这一新逻辑，测一次。
- **训练：** 冻结配方原样，3M、B32、FP32、TF32 关闭、cosine 退火到 0、每条运行自身 p99 裁剪、seed0、固定 11-07 归一化，与本线 k=10 的 3M 参照运行完全相同，只改 k。
- **k=10 格直接复用**本线已冻结配方的 3M seed0 运行，不重训。新运行 3 条：k=1、2、5。

## 3. 评测

- 冻结：七任务 R1、R3（第 6 层 H0，读出种子 0），照现行协议。
- 全量微调：照 `p-recipe` 分支 `docs/p_recipe/USER_DIRECTIVE_20261122B.md` 第 3.1 节协议，任务 qm9.U0_atom、qm9.homo、exp.LogD、exp.LogS，微调种子 0–2。k=10 参照若还没有全量微调结果，补做一次。
- 预训练：固定 VAL 上各家族损失。
- 以分子为单位配对 bootstrap 1000 次（seed 20261025），每格对 k=10 报告 Δ 与 95% CI。

## 4. k* 规则（预注册）

- 每格对 k=10 按现行 τ 与 CI 规则分别判定 frozen R3（七任务均值）和全量微调（四任务、三种子均值的 scratch 参照改善）。
- **本线 k*** = 两种判定都不是 LOSS 的最小 k。
- 只有某个 k<10 格判 WIN，并且会据此采用时，才补 seed1；其余 seed0 终结。
- 本线把 k* 和各格结果写入 上面写明的 `E1_k_star.json` 并在 STATUS 追加一条。P 与 S 共同的 k* 取两线 k* 的较大者，由用户确认后写入主线。

## 5. 解读（预注册）

| 观察 | 结论 |
| --- | --- |
| k*=1 | 在本预算与本人群下，额外构象没有可检出的收益；不写成"构象无用"，并注明 3M 下每个分子平均只被看到约 2.5 次 |
| 1 < k* < 10 | 构象收益在 k* 处饱和 |
| k*=10（k=5 仍判 LOSS） | 构象收益到 10 仍未饱和，如实报告 |
| frozen 与全量微调的判定不一致 | 两者分别报告，k* 按上面的规则取较保守者 |
