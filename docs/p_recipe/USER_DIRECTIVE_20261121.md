## 3. 解读口径（写进报告）

- **只作描述，不做胜负判定**，不触发 seed1、新臂或配方修改，冻结配方不变。
- 9M 运行按自身预算做 cosine 退火：3M 时学习率约为峰值的 75%，6M 时约 25%，9M 才到 0。所以"9M 运行的 3M 断点"不等于"3M 预算训完的模型"，**不和 3M 筛选运行比较**，只看同一条运行内部的趋势。
- 报告写明：R3 在哪个断点之后不再有超过 τ 的提升（τ 取该运行 9M 终点 R3 的 max(0.01, 0.05 × R3)）；若 R3 中途回落而 VAL 预训练损失仍在下降，如实写出。不据此下机制结论。

## 4. 资源与顺序

- 读出排在 9M 训练之后，用 compute-0-0~7 的 24GiB 卡（不占 S 线需要的 ≥36GiB 卡）；bootstrap 和统计放 CPU 节点 compute-0-8~19。先 T2、T1，再 T4、T5、T6。
- 第一个断点读出完成后，日报写一行实测耗时，并据此给出全部 22 个读出的估计。超过估计 1.5 倍只报告，继续。
