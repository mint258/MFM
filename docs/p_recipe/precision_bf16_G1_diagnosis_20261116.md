# BF16 / G1 单步偏差排查（2026-11-16）

结论：本轮未发现规定的 FP32 岛泄漏，保留 BF16 质量作业4532685继续运行，不重启、不修改生产精度方案。排查在用户的2小时时间盒内完成；模型、标签、掩码、归一化及既有FP64数据处理均未改动。

在空闲node20/4090上复用原始固定batch 0/12/13/19、同一G1检查点，执行单步前反向及诊断消融（没有优化器更新）。观测发生在生产`island_tensor`强转之前，另用ATen派发检查softmax/LayerNorm/index_add/scatter及距离偏置首层前向、反向算子的实际dtype和TF32开关；54,183次张量dtype观测未发现违规。距离、d²及RBF与FP32逐元素相同。向量中心原子归约的最大差5.72e-6，在FP32自身重复中也存在，不能据此认定BF16泄漏。归一化、损失及r73数据协议另经源码检查保持原路径。

偏差主要来自FP32 sum池化之后、方案允许使用BF16的H1点积，对相消敏感。固定FP32编码器/池化输入，仅将r460头GEMM改为BF16，在batch13产生最大输出差0.12748（约2.407个固定归一化尺度）；绝对点积项之和最大73.18，而FP32预测幅度不超过0.1801。匹配的4090消融如下：

| 诊断条件 | r460/batch13 损失 | batch0 整模型梯度相对L2 |
|---|---:|---:|
| FP32 | 0.0102182 | 0 |
| FP32重复 | 0.0102172 | 0.000724 |

| BF16编码器、仅所有头恢复FP32 | 0.0156031 | 2.8605 |

这些消融仅用于定位，不构成新增候选方案，也未应用到在跑训练。大偏差是真实精度敏感性；是否合格仍由完整3M质量比较决定，不据此新增数值通过阈值。
