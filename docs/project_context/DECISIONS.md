## PubChem不能丢失的规则

- 标准化/化学范围与v1同代码和RDKit科学版本；原回归一致率≥99.9%的科学门不变。
- 与v1所有声明角色及下游所有划分去污染；候选排序不利用下游标签/分布挑分子。
- wp5键是完整InChIKey的前14字符＋冒号＋最后质子化字符，
  不是通用Bemis–Murcko骨架。两种键的科学用途不能互换。
- R/N排序和完整参考的精确ECFP4/Tanimoto最近邻数学保持，
  不用HOLD丢失的参考子集宣称完整参考。分片必须互斥。
- source NA、component mask、robust-z与新增canonical record mask分别记数。
- Alpha优先源于本轮资源恢复的选择；空闲CPU/并发是每次现场事实，
  不是永久指定节点、CPU数或额外GPU授权。

## 模型科学决策

决策必须在实验前提交，结果出来后不倒改规则。
距离偏置在与最佳差≤1种子SD、且S/P不较基线差>1SD的候选中选最快；
视图2须在S及SDP都处3视图的1SD内且元素/键任务无明显下降。
预测头在最佳1SD内选简单者，同字段跨条件一致；原任务书的特殊字段例外保留。
可学习池化须P提升>1SD。LR/批大小在1SD内偏小LR/大batch。
余弦与WSD在1SD内优先WSD；种子SD从声明重复实验估计。
B*基于开发指标随样本翻倍改善不足1SD的最早平台，统一取S/P较大预算；
若两者差>2倍先报告。具体配方和B*仍需用户确认后冻结。
