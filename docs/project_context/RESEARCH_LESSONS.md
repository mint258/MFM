# 值得保留的科学认识

本页是已记录实验的摘要，不新增因果结论，也不以历史TEST结果选择当前模型。

## 表示、训练图与评价必须对齐

历史融合表示、冻结节点embedding、在线微调的主干和H0不是同一个输入。
比较性能时先查数据身份、角色、标签单位/变换、缺失掩码、指标分母，
再查表示层级、构象、pooling/readout及梯度路径，最后查优化器和checkpoint。
局部解冻、LoRA、缓存特征与端到端执行属于训练图差异，不只是调参。

历史Stage B强MFM路线为：
缓存冻结节点embedding → atomwise MLP → mean/max/std/log_n池化 → MLP。
当时Stage D则为在线主干 → attention weighted sum → projection MLP；
还存在MSE/MAE、task weights及目标空间等差别。
因此其差距不能直接归因“解冻不如冻结”或early stopping。
旧wrapper曾解析inner_val_split却未实际创建内层验证，说明参数存在不代表语义生效。

## ExpansionRx历史结果

2026-05-07已有报告记录25-fold比较：
Stage A conventional_core+CatBoost的CV macro RAE约0.5618，
Stage B冻结MFM/node_gnn/full_mt约0.4987；表征有信号。
历史official结果和排行榜口径另有报告，不能与当前TRAIN-only开发混用。

Stage C旧汇总有四类head因维度错误未完成，只覆盖部分搜索空间，
不能代表完整fusion路线。连续descriptor神经融合曾出现严重数值标定失控，
同时秩相关尚存；应先检查输入标准化、train-fold-only统计、
异常/分布外值、目标逆变换和架构，而非只加容量或调LR。
这是一组特定历史实现的观察，不是所有连续描述符融合必然失败的定律。

MFM、CheMeleon、MACE及指纹/描述符需要在相同数据、split、读出、
梯度和目标空间比较。冻结表征有效不证明端到端微调必然更好；
也不证明融合无价值。改动须有对应对照与负结果。

## S去噪与查找表

历史S修复中，最佳A4两个seed的局部去噪误差约0.052506/0.051682 Å，
高于坐标查找表约0.041299 Å；1层/2层消息补救仍未过原能力门，
原五门为3 PASS/2 FAIL（能力与成本），最终GUIDE_STOP。
不因训练原生C0或其余任务通过而宣称整体科学验收通过。
后续模型v3任务把C2查找表设为分析参照，不能把旧修复硬门迁入新任务。

查找表used_pairs少12曾被误解为漏算；实际12对回退到observed noisy distance，
全部进入误差分母。先读实现和真实分母，不凭统计字段名判断遗漏。

## 数据和数值

PM7优化构象上做去噪存在物理信息混杂；S/P比较不能忽略输入几何本身。
P和P′的差别不仅是字段名，而是程序实际输入几何与相关统计。
.xyz后缀、单帧坐标或成功状态不能单独证明PM7已优化或SCF可靠。
SUCCESS但收敛标记缺失、异常EA等要按实际源检查。

FP32近零逐元素相对误差可能没有科学意义；使用已批准的范数和字段尺度政策，
同时保留FP64硬门和原始观察。单线程严格梯度等价与多线程原实现自身的
非逐位复现需要分开；不能默默放宽allclose再称逐位一致。

训练导出可以F32，权威标签保持原F64。r73顺序、方向和重复本身有语义，
不能为节省存储改成无向成键对。r674平移依赖可能来自非零电荷/偶极的
物理性质，不能未核定义就判标签错误或擅自居中。

## 存储诊断的经验

旧D3的主要体积来自重复JSON/数组描述头、逐记录分页和JSON-hex审计副本，
不是LMDB虚拟map容量。2915库压实预计只省约0.30%，不能据map合计声称可回收TB。
共享schema/字典、避免重复元数据和紧凑数组比单纯收紧map更有效。
v3.1约34.94GB为本次实测；更早70–120GB规划估计不能当实测或容量准入。
任何优化必须保持字段、掩码、身份、原子顺序和有序条目。
