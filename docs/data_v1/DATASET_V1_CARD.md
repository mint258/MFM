# 数据集 v1 暂定试点说明

本卡说明 `v1-pilot-provisional` 的来源、划分、标签和使用边界，接口版本为 D-1 v3.0。该试点用于尽早交接已有完整 S′ 的分子；最终共同人群、D-6 全量导出、D-7 能量/多样性顺序及后台扩充另行发布。

交付状态以正式入口中的状态、实际作业终态和引用链为准。2026-10-30 本卡建立时，D-2 定义字典和 D-5 清单已发布，D-3、D-4 数值交付和 D-5 诊断标签载荷仍在推进。最新运行情况见 [每日汇总](progress_20261031_v1_pilot_provisional.md)。

源数据为现有只读 LMDB、WP5 标签及已完成的普通 S′。本版沿用原始分子、记录和几何来源，保留原子顺序及原标签值；不新增 QM/UFF 来生成该试点。输入文件、Source、实际作业和外部数据文件均由交付 JSON 的 `path / bytes / sha256` 引用链追溯。大数据保存在仓库外部，Git 保存配置、定义、引用和文档。

## 人群、划分和构象

试点固定为 **50,000 个 TRAIN 分子和 5,000 个 ROUTINE VAL 分子**，均在抽样时已有完整普通 S′。VAL 来自用户指定的既有 ROUTINE，按分子留出；原始 `source_role` 与本轮 `effective_role` 分别保存。FULL 来源不能自行当作 VAL 或拟合人口。

已交付 D-5 母清单包含 TRAIN 1,108,366、VAL 7,016。TRAIN 嵌套为 120,000 ⊂ 240,000 ⊂ 600,000 ⊂ 1,108,366，50,000 试点 TRAIN 取自 120,000 子集。该母清单是本轮已有完整 S′ 的冻结暂定人口；最终共同人群后续更新。元素、重原子数和骨架比较由 D-5 入口的 `distributions_manifest_reference` 给出。

`pm7` 与 `uff_sprime` 是独立的几何来源。普通构象、实际程序输入视图、扰动或其他子几何保留各自 GID 和原父子关系；原子数 N、原始索引及固定随机秩均保留。该版可用顺序为 `fixed_random`；能量、多样性、最低能量顺序随 D-7 发布，消费方不得用固定随机顺序替代它们。

S′ 补齐和后台新分子不会静默加入这次冻结试点。新人口及其归一化必须使用新的明确版本。

## 标签、精度和掩码

D-2 覆盖 146 个有值且非常数的原分量；分量和模型物理预测头的对应关系以实际 mapping 为准。现有字典核得分子级标量为 43 个 P、26 个 D；另有原子级 `SASA_atom_A2`。原始 63 个 registry 字段按设计 N/A，不补算；10 个常数壳层分量的删除原因保留。具体定义见 [注册表报告](label_registry_v3.md)。

训练导出按家族拆分为 float32 LMDB，使用 typed codec，不写 pickle。原始/永久标签及数值旁车保持 F64；训练端仅执行一次 F64→F32 转换。整数 ID、原子顺序、原子对索引、有效掩码和原因码分别保留。

r73 的 F64 权威条目保留有序端点、两套 basis/channel、方向、重复条目、onsite 信息及 entry ordinal。不得排序合并、对称化或先转低精度再重建权威副本。r674 保留原值、部分值、六分量掩码及几何信息，v1 维持 `LOSS_DISABLED`；不追加 QM，不在此版做质心原点换算。原 MolMR 单位仍为 UNKNOWN，相关物理损失关闭。

物理/状态/范围等掩码只作用于标签。源缺失、源异常、人工复核、损失可用性和是否进入拟合为不同信息；不因某个标签无效而删除整个记录。新增掩盖比例及原因、严重样例和稳健 z 诊断以实际统计报告为准；超过原 1% 门的字段须单独报告，不通过文档放宽科学规则。

已有 Se 不支持分子的单元素排除率例外按用户授权保留，仍排除不支持分子。其他元素及质量门不变。历史未独立观测的坐标证据继续如实标 UNKNOWN；不填写零/单位矩阵作为数值 frame。

## TRAIN-only 归一化

D-4 只基于试点的 50,000 个 TRAIN 分子及其合格拟合记录计算。VAL、诊断留出目标、最终共同人群之外的新数据都不参与拟合。D-4 与 D-3 必须绑定同一人口和同一掩码/目标政策。

能量类字段在 TRAIN 上拟合元素计数参考，保存系数和残差统计；生成热在扣除元素参考后再按原规则判尺寸相关性。尺寸家族规则使用实际 TRAIN Spearman ρ，阈值为 |ρ| ≥ 0.95；不能用历史人口或未校正生成热的相关性代替本轮结果。

按原方案在第 0.1 与 99.9 百分位缩尾后计算统计量。缩尾仅用于拟合统计，不改写训练标签。按元素统计、均值、标准差、边界和元素模型以 D-4 的实际系列及 target policy 读取。矢量、张量和有序条目遵从冻结的目标类型与尺度规则，不能套用未经绑定的通用中心化。r674 的损失仍关闭。

同一套 TRAIN 输入进行两次独立数值重放并比较。尺度未绑定或退化的目标按明确状态处理，不能用默认 s=1。P′ 使用独立统计量，不借用 PM7 的 P 统计；后台 P′ 尚未完成的统计不作为本试点的完成条件。

## 已见分子、未见构象诊断

原 D-5 全局诊断清单选 20,000 个 TRAIN 分子，每个分子各留最后一个固定随机 PM7 和普通 S′ 构象；要求两种来源各至少两个构象。全部相应 base、子几何及实际输入视图在取训练前 k 个构象之前排除。原 N 和原秩不重编号。这是对同分子构象划分规则的明确例外，**只诊断预训练损失，不用于模型选择**。

试点诊断标签补充只覆盖“实际 D-3 已导出的 50,000 TRAIN”与原 D-5 全局 20,000 的真实交集。交集数量及交集外数量由实际 CPU 导出报告，不能直接宣称试点拥有全部 20,000 个诊断分子。清单中的已留出不代表标签已导出；诊断载荷有独立入口和实际 C0 证据。

诊断样本保留分子的 `effective_role=TRAIN`，同时显式设置 `sample_role=TRAIN_UNSEEN_CONFORMATION`、`diagnostic_only=true`、`training_excluded=true`。原值和科学掩码保持；拟合排除不冒充科学无效。采样只从诊断索引的 `is_base` 进入 UNSEEN，派生几何随原父子关系附着，不增加 N。UFF 诊断几何不填入尚未计算的 P′ 标签。

## 使用和验证

实际 D-3 在同一正式 Parent 内完成原 3 项 Source 检查、10,000 条源记录逐字段对照、永久 F64/单次 F32 转换校验、真实计数闭合和 16 个实际 reader 的读回。消费方沿 D-3 `store_references` 及其 F64 authority 读取，不扫描目录拼接猜测版本。

CPU 共享盘读测与 GPU 节点物理本地磁盘读测分别报告。GPU 本地复制、完整 SHA、实际磁盘空间和多 reader 吞吐在模型线已经准入的真实 GPU Parent 的 I/O 阶段执行，保留宿主原资源监测与 UUID 锁。实际大小、冷热状态和吞吐以该 Parent 的执行收据为准。

数据侧接入方法见 [暂定载荷 bridge](../../workflows/data_v1_final/export/provisional_fast55k_adapter_v1/README.md)。D-1 政策签认、文件 SHA、数据侧 reader 通过和模型实际 payload 加载验收分别保存。模型 Root 根据实际 typed 解码/载入结果确认；数据侧不自行填写 Model payload ACK。

## 异常与已知限制

本版人口、统计和顺序为暂定范围；final Common、D-6/D-7、完整 P′ 与后台新分子另行发布。没有发布的目标、几何、尺度或顺序不能补默认值。

当前 r73 数据可完整运输和读取；训练消费者若要求尚未绑定的数值 origin/basis，将明确拒绝该目标请求。不同程序输入/扰动几何的 typed 目标必须绑定其实际 GID；消费方应完成对应路由，不将子几何标签贴到父几何，不填伪目标。这些接入限制在 bridge 文档中逐项说明。

MoleculeNet/COCONUT 已知问题按本轮失败上限保守挂起，其余去污染及 PubChem/P′ 在后台继续。后台输出只按各自实际验收状态进入相应版本，未过滤池不进入训练清单。

该卡的文字由已冻结政策和实际已交付清单编写；未知数值、未来哈希和未来终态均不预填。数值统计、掩码数量、文件大小、吞吐和模型加载结论以脚本产生并经实际终态核对的正式引用为准。
