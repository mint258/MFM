## Explicit closed-parameter checkpoint mode

Training normalization does not depend on later diagnostic median/MAD. Original element_reference, normalization_quantiles and normalization_moments purposes must all be committed in a real full-input checkpoint (purpose_index3). The new --pm7-closed-checkpoint argument is mutually exclusive with the unchanged --pm7 completed-manifest mode. It consumes only original element_models_reference, exact_tail_reference, winsorized_statistics_reference, original field map and existing full Common TRAIN anti-D5 eligibility. It checks closure/source-reference metadata only, without opening eligibility SQLite or scanning observations, Parquet, caches, arrays or replaying statistics. Full source/fit eligibility and exact-tail input bindings must match the committed original input. Incomplete purposes, pilot/non-TRAIN inputs or a different source binding are rejected. A checkpoint whose diagnostics already finished uses the original post-C0 mode instead.
