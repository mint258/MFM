A completed reduced projection table is also recorded after its SQL commits; restart reuses it and calls Native only for unclosed batches. Incomplete tables/files are retained with unique names, never deleted or mistaken for closed outputs. Resume input-path binding prevents mixing a different scientific source set; it does not perform new source audits, hashes or QA.

New final-order files use the tail subdirectory; existing files are not overwritten. Original overall COMPLETE/PARTIAL status semantics are retained, including the actual known masked source failures.
