## 阶段 1：真实结构覆盖与比较组

**问题：** 数据是否真的提供了我们希望研究的变化？多记录是否只是同一个或非常相似的几何？

**输入与单位：** 固定核心/富集面板的分子图、实际 P 目标所对应的几何及原子映射。先使用结构选择，后查看标签差值。

**固定工作：**

1. 在面板中分别统计分子、连接图、分子式组、每分子记录数、允许构象数。复用已有 D7 的可连接结果；未覆盖的面板记录按原定义计算。
2. 几何主口径沿用固定源重原子对应、proper Kabsch、不反射、0.5 Å、fixed_random 贪心代表。补充全原子 RMSD、已存在重原子可旋转键的二面角变化和源图非键重原子接触距离变化，保留连续值，不另开阈值扫描。
3. 非键重原子对定义为图距离至少 3；每分子至多 hash 选 128 对作局部距离摘要，不生成无界全原子 pair 表。二面角由既有键和源原子序号确定；缺少可靠图/原子对应时仅该指标记不可用。
4. 冻结下表三类标签比较。刚体对齐后的 0.5 Å 分类只表示几何统计口径，不能当作所有性质的敏感性阈值。

| 比较 | 固定方式 | 标签比较上限与报告单位 |
| --- | --- | --- |
| 跨组成参照 | 仅核心；按 hash 顺序形成不共用分子的对，跳过同分子式配对，不按标签挑选 | 至多 1,500 TRAIN + 150 VAL 对；每分子使用首个允许构象的图级标量 |
| 同式不同连接结构 | 富集面板每组至多 4 个不同连接图；每组内部全部不重复分子对 | 至多 3,000 TRAIN + 300 VAL 分子对；仅比较图级标量和已有合法图级不变量；组为统计单位 |
| 同分子构象 | 相同图、立体身份、质子化、方法/状态/环境；在至多 10 个构象的无序对中按 hash 选至多 6 对 | 至多 30,000 TRAIN + 3,000 VAL 构象对；分子为统计单位 |

不足上限时使用实际数量，不重复填充。主几何覆盖允许计算每分子的全部至多 45 个几何距离，至多 247,500 次；标签主配对始终为预先选定的至多 6 对。原有扰动几何路由只在这些冻结配对上另算至多 33,000 次，合计最多 280,500 次几何比较；不新增扰动结构。

近似重复与差异明显的构象对均保留并分别报告。近似 RMSD 不等于物理完全等价。只有实际同几何、同条件的独立计算，才可进入计算重复性对照。

**输出：** 01_STRUCTURE_COVERAGE.md、coverage.json、配对规则与外部 pair manifest 引用；一张“记录数与真实几何覆盖”图。选最多 12 个标签无关的结构案例用于后续贯穿解释。

**完成条件：** 面板与配对固定，实际独立单位数明确。缺少同式组或多构象时给出覆盖不足，仍继续其他层次。

## 阶段 2：数值分辨率与等价对照

**问题：** 哪些差异能被现有数据可靠分辨？哪些只能证明“浮点数不同”？

**输入与单位：** 本面板定点读取的权威标签、原程序打印/收敛信息、已有实际重复计算与适用的物理审查。

**固定工作：**

1. 分开登记输出舍入、历史生成器转换、FP64/FP32 表示、收敛/重复计算和方法准确性。容器位宽不作为计算误差估计。
2. 对有明确误差界的字段传播两端差值误差；对经验重复结果报告原单位分布和独立样本数，不把几次复算最大差值声称为全域误差上界。
3. 标量按不变量比较；向量/张量先按已定义坐标变换比较，带电体系涉及原点时使用已有正确变换。原子/pair 字段使用源对应；重读或重新导出同一条值不算独立计算。
4. 人工旋转坐标并复制标签只能验证接口变换，不能算物理正确性或独立计算重复。复用已有同类接口验证，不为本版再造旋转测试套件。
5. 每字段至少标记：有适用的计算精度证据；只有打印/存储分辨率；条件未知/不适用。没有化学意义阈值时报告连续差值，不自设统一“化学显著”阈值。

**条件子项 2B：最多 32 次单点校准，默认跳过。**

仅当生成热或 xTB 能量这些关键家族没有适用的已有计算精度证据，导致阶段 3 的主要问题只能停在“超过存储分辨率”时触发。先检索已登记的对应输出，不重新开展源目录普查。

- 只从冻结 TRAIN 核心按面板顺序取前 4 个具有至少两个真实不同、状态与几何明确的分子；每分子取已冻结配对中重原子 RMSD 最大的一对，标签值不参与选择。

- 两设置为原设置与数值 SCF 收敛标准严格 10 倍；必须使用原版本支持的参数。调用前将从原配置/程序说明确定的具体参数名与值写入小配置，不能同时改变几何、理论方法、电子温度、溶剂或电子态。
- 已有原设置输出足够可比时直接复用；不重跑这一半。无法独立调节所需数值条件的组合记为不可执行，不换方法补齐。
- 不做几何优化。每调用 1 CPU、最长 300 秒，至多 4 个并发；失败记缺失，不追加重试。总计最多 160 CPU 分钟。

## 阶段 3：控制组成后的条件区分度

**问题：** 大的跨组成差异以外，结构与构象变化是否在标签中留下可辨识的信息？

**输入与单位：** 阶段 1 固定比较组、阶段 2 分辨率层级、原单位标签与 mask。只有双方定义/条件相容且有效的字段进入该字段比较；分母另外保留所有候选对。

**固定计算：**

1. 跨组成图级标量直接比较原单位差值，给出中位数与 P10/P90。
2. 同式不同连接结构仅比较图级标量和已有明确定义的图级不变量。每分子保存有效构象数、中位数、最小值与最大值；主差异为两分子构象中位数之差，并列两侧范围；附报首个允许构象的差值。只有一个有效构象时明确标记单点，不把范围 0 当作已证明无构象变化。构象样本中位数不是热力学平均，异构体差异也不能完全归因为连接关系。
3. 同分子构象对计算实际物理差值；原子标签报告对齐后的 RMS 差和最大局部差，并按元素分开；pair 只比较源中已有、映射一致且双方有效的有向端点，不创建新 pair 标签。
4. 对向量/张量分量差，先按实际几何对应和既有规则做变换；无法确定对应的字段只报告已经有定义的合法不变量或记未知，不把坐标分量变化当物性变化。扰动几何路由单列，解释其标签差异时使用真实扰动几何，不把扰动引起的变化完全归因于原始构象。
5. 使用已有 D4/A1 元素参考展示组成分量、残差及原固定尺度下的差值幅度。对同组成/同分子对，元素参考在原单位差值中抵消；标准化幅度变化单独报告，不当作新增信息。没有已发表参考的字段不临时拟合替代模型。
6. 分别报告：可靠可分辨、仅超过存储分辨率、当前证据下未分辨、不可比较。每类都给独立分子/公式组数量、有效候选分母与连续差值；数值完全相同、误差范围内相同和缺失不能合并。

用于阶段 4 的每字段主差异量固定为：图级标量的绝对差（同式分布比较为中位数绝对差），图级向量的对齐后 L2 差，图级张量的 Frobenius 差，局部标量/向量/pair 的共同有效位点 RMS 差。局部最大差与分布范围是解释性摘要，不在看到结果后替换主统计量。

核心与富集、TRAIN 与 VAL 分开呈现。组内配对先等权汇总，再对分子或分子式组等权；禁止原子多或构象多的分子获得额外样本权重。按分子/分子式组做 1,000 次 bootstrap，seed 20261025，给 95% 区间；它描述冻结面板内部稳定性，不宣称全人口无偏估计。跨组成不共用分子的对以对为单位。

不要求能量随 RMSD 单调；不要求所有不同结构都有不同标量标签。没有观察到差异时，结合阶段 0 的物理预期与阶段 1 的覆盖给结论。

**输出：** 03_CONDITIONAL_INFORMATION.md、conditional_information.json；三类比较的差值/分辨率图、代表性同式组与构象案例图。总体方差或相关秩可以引用已有报告，不能作为本阶段判决。

**完成条件：** Q3/Q4 在每个家族、每类变化上的证据明确；正、负和无法判断均为有效完成结果。

## 阶段 4：联合信息、标签碰撞与选择性缺失

**问题：** 单个字段看不到的变化是否能由其他家族补充？有效率是否掩盖了特定化学子群的信息缺失？

**固定工作：**

1. 先列注册表中可证明的代数关系、单位换算或来源复制，再在固定结构对上检查条件相关。五状态绝对值相关不能代替其状态差值是否随结构变化的分析。
2. 每个比较层级固定参与联合判断的现有家族集合及共同可比较结构对。每字段主差异量 d_j 沿用阶段 3 定义，以已有正 D4 尺度 s_j 作单位归一化，家族统计量为 T_f = max_j(d_j/s_j)；尺度不充当噪声界。等价对照须使用相同字段、差异定义、尺度、有效维度与适用条件；局部字段还须匹配有效位点数及映射。无适用尺度或对照的部分保留单字段/未校准描述。
3. 有确定差值误差界的字段按传播后的界判断，并保持“计算可靠性/仅打印存储精度”的证据层级分开。经验噪声用家族 T_f 的等价对照尾概率 p_f = (1 + 对照中 T_f 不小于观察值的数量)/(1 + 对照数)。对每一结构对，按固定完整家族集合做一次 Holm 0.05 校正；不可检验家族保留在校正家族数中、以 p=1 作保守占位，科学状态仍为未知。固定各家族检出指示 D_f 后，再比较全部家族与去掉某家族的检出并集；删除家族时不重新校正。独有补充分辨率是 D_f=1 且其余家族均 D=0 的组加权比例，只说明独有检出，不意味着其他家族无信息。
4. D_f=0 表示当前规则下未检出；缺失或校准不足为 null。对照数量或适用性不足时，只报告未校准距离和原因，不把未知写成不可分辨。联合率限于相关家族均可判断的共同配对，并报告其覆盖分母。32 次案例校准不能提供全域检验依据；少量复算最大差值不进入确定误差界通道。
5. 列出所有可比较字段在分辨率范围内都相同的结构对；最多保留 12 个按固定 hash 选出的案例解释。逐例区分预期不敏感、覆盖不足、源值可疑重复、条件不全和误差未知。
6. 同时统计记录有效率、两端共同有效率、每分子可用配对数。按子集实际来源、重原子数（≤20、21–35、>35）、任务状态、可旋转键数（0、1–3、≥4）、真实构象覆盖分层。稀有类别报告实际分母，不新增已排除的金属/离子体系。

原子电荷等局部字段保持原子对应，不先求分子均值再宣称其无信息。缺失模式不算标签数值提供的信息。同式跨连接组不构造原子或 pair 的逐项对应；原子/pair 的局部差值分析仅用于同一分子的构象对。

**输出：** 04_JOINT_INFORMATION_AND_MISSINGNESS.md、family_complementarity.json、missingness.json；家族互补矩阵与配对覆盖图。

**完成条件：** 能说明哪些家族提供互补信息、哪些高度重复、哪些结论受选择性缺失限制；校准不足如实保留。

## 阶段 5：来源至训练端的差值保留与结论

**问题：** 原始数据有的结构信息，模型实际接收的数据是否仍保留？

**输入与单位：** 相同冻结记录/配对的原始精度证据、WP5 权威值、pilot MFM4、当前 D6 同物理记录与实际 P loader。标签/几何读取与前面阶段共享缓存或聚合摘要，不重扫母集。

**固定工作：**

1. 沿原输出/typed 值 → 权威标签 → 导出 → loader 单位/参考/尺度/裁剪/掩码，逐级记录同一对的数值差异。若前面的原始输出不存在，明确从最早可追溯层开始。
2. 对原始可分辨差异，报告差值归零率、差值误差、符号翻转率（仅原始有可靠方向的标量对）、掩码改变、字段/原子错配；同时给各项分母。
3. 记录原始几何不同而训练端几何变相同的比例；扰动字段使用实际扰动几何。源相同但 loader 值异常不同则报告反向伪差异。
4. 不能用大绝对值的相对误差通过来替代小差值保留。仅可逆缩放造成的幅度变化，与量化、裁剪、掩码或错误路由引起的不可逆损失分开。
5. 对已发表 D4 和 A1 的离线应用只比较信息与幅度，不选择新配方，不据此改在跑模型。

**最终结论表：**

| 结论 | 所需证据 |
| --- | --- |
| 相关结构覆盖不足 | 面板缺少该类可比较结构/构象 |
| 物理定义或条件不完整 | 同一任务无法确定实际对象、状态或几何 |
| 有效但对该变化预期不敏感 | 定义支持这种不变性，观测与之相容 |
| 当前分辨率下未分辨出差异 | 覆盖、误差依据和观察范围同时给出 |
| 只有存储层面可分辨 | 差异超过打印/存储误差，但计算可靠性未知 |
| 存在可靠的条件信息 | 有真实结构变化，差异有适用的可靠性证据 |
| 信息与其他家族重复或互补 | 在同一比较集合上完成联合分析 |
| 信息在处理链中损失或错位 | 同一物理记录的前后层差值证据 |
| 信息保留但相对幅度很小 | 原始差异仍在，只发生可逆尺度变化 |

结论按“性质家族 × 比较层级 × 证据范围”给出，允许同一字段在不同层次获得不同结论。不用一个总分把整个 P 判好或坏；不从少量可靠字段推断所有 P 字段已排除数据问题。

**输出：** 05_PIPELINE_RETENTION.md、retention.json、FINAL_REPORT.md 和结论矩阵。最终报告逐条回答 Q1–Q7，并说明哪些问题已有数据证据、哪些仍未确定。后续训练建议最多列为待议，不执行。
