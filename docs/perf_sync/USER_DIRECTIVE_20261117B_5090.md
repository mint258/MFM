# 提速线补充指示二：在 5090 上复测（用户 2026-11-17 晚）

适用：提速线（分支 perf/sync-free-20261117）。本指示是在 3090 结果出来之后给出的，覆盖与之冲突的条款，其余规则不变。

## 为什么要在 5090 上复测

3090 的 S0 显示 GPU 忙碌 71–78%、每步约 4900 个 kernel，训练主要受 GPU 限制。所以去同步、减少 kernel 数、加核数这类改动在 3090 上几乎测不出效果；S7 中 4 核和 24 核只差 0.34%。

5090 的情况很可能不同。主线第 3 轮里，5090 只有约 65 样本/秒，与 4090 的 65.4 样本/秒几乎一样，GPU 明显吃不饱。9M 确认运行也主要在 5090 上跑。所以**在 5090 上把所有改动重测一遍**。3090 的结果保留不变，不重测。

用户已确认 9M 先按"全部开关关闭"冻结。如果 5090 的复测找到有效开关，由用户决定是否在 9M 提交前改用。9M 本来就要等 C3 和 M3，复测预计比它们先完成。

- 基准配置仍是 `round3/M2.json`（当前最优配方），B32，FP32/TF32 关闭，14 个读进程，16 CPU。

## 测量方法的两处修正（3090 那一轮暴露出的问题）

### 1. 测速要抵消漂移

3090 上的 S8（全部关闭）也比基线快了 4.05%，说明测速存在约 4% 的系统漂移。所以：

- 每个候选开关按 **基线 → 候选 → 候选 → 基线**（ABBA）的顺序，在同一张卡上连续测 4 次。提速倍数 = 两次候选的平均值 ÷ 两次基线的平均值。
- 同时记录两次基线之间的差距，作为噪声。
- **"提速有效"**：提速倍数 ≥ 1.05，且提速幅度大于两次基线差距的 2 倍。

### 2. 数值验收改为有噪声参照

**单步梯度：**
- 门槛 10·ε_grad 只用在**随机初始化**的权重上。
- 在训练好的 B3 checkpoint 上，任何改变浮点求和顺序的改动都会产生 1e-3 量级的相对差。这是模型本身的数值敏感性（与 BF16 诊断中的点积相消是同一个现象），按这个门槛，PR8 已采用的分组运算也通不过。所以训练好的权重上只报告偏差，不作为门槛。
- ε_grad 和 ε_loss 在这张 5090 上重新测一次。

**短训练等价性（只对测速有效的候选做）：**
- 基线用 seed 0 和 seed 1 各跑 1000 次更新，共 2 条，所有候选共用。
- 候选也用 seed 0 和 seed 1 各跑 1000 次更新。
- 记 L 为末 200 次更新的平均总损失，噪声参照 N = |L(基线, seed0) − L(基线, seed1)|。
- **通过**：两个种子都满足 |L(候选, s) − L(基线, s)| ≤ N + 0.01，且全程没有 NaN/Inf。
- 3090 那一轮固定的 0.0236 门槛作废。

开关属于 A 类（应逐位一致）的，先检查是否逐位一致；不一致就按上面的 B 类流程处理，不另设流程。

## 要做的测试（按顺序，在同一次 GPU 分配里连续做完）

1. **S0（5090）**：按原 S0 方法采集 GPU 忙碌占比、每步 kernel 数、每步同步次数及位置、主线程发射时间、H2D 拷贝；测噪声底。
   - 只报告 GPU 忙碌占比，**不据此跳过任何后续测试**。
2. **S1–S5 的 ABBA 测速**：S1、S2、S3、S4（encoder 和 encoder_heads 两种模式）、S5，共 6 个候选。
3. **S1b 补充去同步（有条件）**：
   - 条件：5090 的 S0 显示 GPU 忙碌 < 70%，并且 S1 之后每步同步仍 > 20 次。
   - 内容：只针对 S0 实测列出的剩余同步点（PyG dense、bincount、分组损失等），在 `step_overhead.sync_free` 开关下补齐预计算，时间盒 4 小时。
   - 完成后作为 S1 的新版本，重测 ABBA。不满足条件就记"不适用"。
4. **S7（5090）**：用基线配置扫描 4 / 8 / 16 / 24 核 × 14 个读进程。只在节点实际空闲的核数范围内扫，每格测 1 次。用来回答"在 5090 上加核数有没有用"。
5. **短训练等价性**：只对第 2、3 步中测速有效的候选做。
6. **S6 CUDA Graphs**：只有在某个版本的 S1 做到每步零同步时才做，否则记"不适用"。
7. **S8 累计组合**：把所有"提速有效且等价性通过"的开关一起打开，做一次 ABBA 测速和一次两种子短训练等价性检查，给出相对基线的总倍数。
