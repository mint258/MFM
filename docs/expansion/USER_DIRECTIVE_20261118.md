- 真实磁盘、inode、配额保护和 200 GB 余量；
- Root 统一提交；
- 每日一页汇总。

## 1. 第二批扩充（250 万）

- **来源：** 已落盘的 R/N 各 500 万有序嵌套队列里，各取第 1,250,001–2,500,000 名，共 250 万。不重算全池近邻、排序或去污染。
- **流程：** 和首批完全相同。
  - S′ 参数、固定候选、种子和生成顺序不变；30 个候选，0.5 Å 去重；
  - 每个分子最多 3 个实际 UFF 构象，不补足，不做科学重试；
  - D20 每分子一次，D3 和原子 SASA 逐实际构象。
- **首批后来补上的规则，第二批从一开始就用：**
  - 立体化学补充：未指定立体中心的分子，最多 4 次立体抽取；
  - 单分子累计 3600 秒硬截止。到点结束独立进程组，记为 UFF_TIMEOUT/unknown，不重抽。
- **交付：**
  - 和首批同格式的批次报告和唯一最终清单；
  - 固定 100 万查询的覆盖更新：参考集加入第二批，查询、顺序、指纹和整数运算口径不变。
- **存储：** 首批最终约 120 GB Parquet，另有 Alpha 工作目录约 133 GB。开始前按既有规则做跨窗口峰值预算。预算加 200 GB 余量放不下时，就换已核实的空间或分批做。实在没有可用空间：停在可续传状态，写进日报"待用户决定"，**不删除任何文件**。
- **并发：** 只在 CPU 节点 compute-0-8 ~ compute-0-19 和 Alpha 上没有 GPU 的主机提交，不占任何 GPU 节点的 CPU（含 compute-0-20/21/22，见 AGENTS.md 2026-11-18 规则）。以前用过的 compute-0-2 不再新提交。不申请 GPU，不用付费服务器，不动他人作业。
