# head 类型线补充指示（用户 2026-11-17）

适用：head 类型线（分支 p-heads-20261117）。本指示覆盖任务书中与之冲突的条款，其余规则不变。

> 编号说明：本线的 T0–T5 是本线自己的臂，与配方线 9M 确认运行的 T1–T7 无关。日报和文档中提到配方线的 9M 运行时，写"配方线 9M-Tk"以示区分。

## 当前最优配方

当前最优配方 = 配方线的 M2（A1 + B3 + B4，`configs/p_recipe/fixed_20261115/round3/M2.json`，运行名 `fixed_20261115_round3_M2_infra_recovery_20261117_sbatch`，3M 时 R3 = 0.4680，R1 = 0.2975）。M2 与 B3 的差距在单种子噪声以内。配方线会发布 `configs/p_recipe/CURRENT_BEST.json`；之后**新启动**的运行以该文件为准，已在跑的运行保持原基底。

## 1. T1：直接训练，取消逐头验收

- **用户决定 T1 直接开始 3M 训练。** 之前的 64 样本验收不适合 T1：它复用的是 B3 已经训练好的原子头，初始 loss 已在 1e-4 量级，"降到 1%"无法达到；lr 0.003 反而把这些已收敛的头推坏了。正式 3M 训练从头开始，头部是新初始化的；解码器两个残差支路的输出层零初始化，起始时等价于恒等映射，单元测试已经证明。
- **路由**：全部 45 个原子级和成对字段都经过解码器（`atom_decoder_fields` = 全部 45 个）。
- **基底改为 M2**（不是 B3）：由 `round3/M2.json` 复制，只加 `atom_attention_decoder` 和运行名/路径相关键，执行键保持与 M2 相同。
- **对照**直接复用配方线的 M2 3M，不重训。
- **判定**：沿用本线任务书规则。单种子满足 |Δ| ≥ 0.06 且 CI 不跨 0 时直接判定；否则补跑 T1 seed 1，对照的 seed 1 **复用配方线的 M2 seed 1 运行**，本线不另跑。

## 2. T2、T3：照常跑完，不改基底

- T2、T3 继续在 B3 基底上跑完，不停止、不迁移，按原规则与 B3 比较；需要补 seed 1 时，按原规则由本线补跑 B3 seed 1。
- **T2 若判为胜出**：在 CURRENT_BEST 基底上补一条 3M 确认运行（seed 0），对照复用配方线该配方的运行。
- T3 是机制消融，不需要换基底。

## 3. 新增 T4、T5：拆解 B3 的增益来源（直接启动，与 T2、T3 并行）

**原因**：H6 显示 PMA 的 query 注意力接近均匀（熵中位数 0.959），所以"按内容选择原子"的解释不成立。PMA 的分子向量 z 由三部分组成：8 个 query 块（512 维）、64 维 sigmoid 门控求和、log N。需要弄清增益来自哪一部分。两条都在 **B3 基底**上做，与 T3 直接可比，对照是 B3。

| 臂 | 唯一改动 |
| --- | --- |
| T4 门控关闭 | 门控求和支路的 sigmoid 门固定为 1，即普通的 sum / N_ref。其余与 B3 完全相同 |
| T5 简单读出 | 去掉 PMA。每个分子级标量字段读 [mean(H), sum(H)/N_ref, log N]（1025 维）后接线性层，原子级部分与 B3 相同 |

- **验收**：只为新逻辑写单元测试（T4 门恒为 1；T5 的输出维度与 padding 排除；开关关闭时逐位一致），**不做逐头验收**。正式训练从头开始，3M 训练本身就是真实使用的验收。
- **判定**：与 T1–T3 相同的规则，对照为 B3。
- **结果解读**（预注册，写入本线的 preregistration 补充）：

| 观察 | 结论 |
| --- | --- |
| T3 ≈ B3 且 T4 明显低于 B3 | 增益主要来自门控求和 |
| T5 ≈ B3 | 只要同时提供强度汇总、广延汇总和分子大小，就足以解释大部分增益 |
| T3、T4 都 ≈ B3，T5 明显低于 B3 | 增益来自 query 之后的非线性处理 |

  其他组合如实报告，不追加臂。

## 4. H 部分补充（零训练）

1. **在 M2 上重做 H4**：用 M2 的 checkpoint，对 z 和 [mean(H6), z] 做 R1/R2，协议与 H4 完全相同。目的是确认 B3 上"分子向量拼接后接近 R3"这一结果在当前最优配方上也成立。
2. **H7 门控落点**：在 B3 和 M2 上，读取门控求和支路每个原子的 64 维 sigmoid 门值。用与 H6 相同的 5000 个分子、相同的原子类别和 bootstrap，报告每一维门值的类别富集，以及门值的分布（均值、标准差、跨原子方差占比）。只作描述，不设判定。
3. T1–T5 各自的最终 3M checkpoint 产出后，补算 H1 的第 6 层几何。

## 资源与顺序

- 新增训练：T1、T4、T5 各 3M，约 30 GPU-h；加上可能触发的 seed 1。
- T1、T4、T5 互相之间、与 T2、T3 之间都没有先后顺序，哪条先就绪就先上空闲卡。
- 空闲卡的优先顺序：提速线（直到其 GPU 部分完成）> 配方线 > 本线与任务解耦线。

- 不为 T1、T4、T5 做逐头验收，不调 lr 或其他超参数。
- 除本指示列出的之外不加臂，不跑 9M，不修改 `docs/paper/`（论文素材由用户和 Claude 更新）。
